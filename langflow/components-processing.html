在 Langflow 中处理组件 ​

处理组件在流程中处理和转换数据。

在流程中使用处理组件 ​

在此流程中，拆分文本处理组件将传入的数据拆分为块，以便嵌入到向量存储组件中。

该组件提供对块大小、重叠和分隔符的控制，这会影响到向量存储检索结果的上下文和粒度。

更改元数据 ​

该组件用于修改输入对象的元数据。它可以添加新的元数据、更新现有元数据，以及移除指定的元数据字段。该组件可以处理 消息 和 数据 对象，还可以根据用户提供的文本创建新的数据对象。

Inputs ​

名称显示名称信息
input_valueInput将添加元数据的对象
text_inUser Text文本输入；值将在 Data 对象的 'text' 属性中。忽略空文本输入。
metadataMetadata要添加到每个对象的元数据
remove_fieldsFields to Remove要移除的元数据字段

Outputs ​

NameDisplay NameInfo
dataData输入对象的列表，每个对象附加了元数据

合并文本 ​

该组件使用指定的分隔符将两个文本源连接为一个单一的文本块。

输入 ​

名称显示名称信息
first_textFirst Text要连接的第一个文本输入。
second_textSecond Text要连接的第二个文本输入。
delimiterDelimiter用于分隔两个文本输入的字符串。默认为一个空格。

输出 ​

名称显示名称信息
messageMessage包含合并文本的 Message 对象。

此组件为遗留组件，这意味着自 Langflow 版本 1.1.3 起，它已不再处于活跃开发中。

该组件动态创建一个具有指定字段数量的数据对象。

Inputs ​

名称显示名称信息
number_of_fieldsNumber of Fields要添加到记录中的字段数量。
text_keyText Key用于标识作为文本内容的字段的键。
text_key_validatorText Key Validator如果启用，将检查所提供的 Text Key 是否存在于所提供的 Data 中。

Data combiner ​

INFO

important

在 Langflow 1.1.3 版本之前，该组件被命名为 Merge Data。

该组件将多个数据源组合成一个统一的数据对象。

组件遍历输入的数据对象列表，将它们合并为一个数据对象。如果输入列表为空，则返回一个空的数据对象。如果只有一个输入数据对象，则返回该对象不变。合并过程使用加法运算符来结合数据对象。

Inputs ​

NameDisplay NameInfo
dataData要合并的数据对象列表。

Outputs ​

NameDisplay NameInfo
merged_dataMerged Data一个单一的 Data 对象，包含来自所有输入数据对象的合并信息。

DataFrame 操作 ​

该组件对 Pandas DataFrame 执行以下操作：

操作描述必需输入
添加列添加一个具有常量值的新列new_column_name, new_column_value
删除列移除指定的列column_name
过滤基于列值过滤行column_name, filter_value
取前几行返回前 n 行num_rows
重命名列重命名已有的列column_name, new_column_name
替换值替换列中的值column_name, replace_value, replacement_value
选择列选择特定列columns_to_select
排序按照列对 DataFrame 进行排序column_name, ascending
取后几行返回后 n 行num_rows

Inputs ​

名称显示名称信息
dfDataFrame要操作的输入 DataFrame。
operationOperation选择要执行的 DataFrame 操作。选项：添加列、删除列、过滤、头部、重命名列、替换值、选择列、排序、尾部。
column_nameColumn Name用于操作的列名称。
filter_valueFilter Value用于筛选行的值。
ascendingSort Ascending是否按升序排序。
new_column_nameNew Column Name重命名或添加列时的新列名称。
new_column_valueNew Column Value用于填充新列的值。
columns_to_selectColumns to Select要选择的列名称列表。
num_rowsNumber of Rows返回的行数（用于头部/尾部）。默认值：5
replace_valueValue to Replace要在列中替换的值。
replacement_valueReplacement Value用于替换的值。

Outputs ​

NameDisplay NameInfo
outputDataFrame操作后的结果DataFrame。

Data to message ​

important

在 Langflow 1.1.3 版本之前，该组件被命名为 解析数据。

ParseData 组件使用指定的模板将数据对象转换为纯文本。该组件将结构化数据转换为易读的文本格式，并通过使用模板实现可定制的输出。

Inputs ​

名称显示名称信息
dataData要转换为文本的数据。
templateTemplate用于格式化数据的模板。它可以包含键 <code>{text}</code>，<code>{data}</code>或数据中的任何其他键。
sepSeparator多个数据项之间使用的分隔符。

输出 ​

NameDisplay Name信息
textText结果格式化的文本字符串，作为一个 Message 对象。

JSON cleaner ​

JSON cleaner 组件用于清理 JSON 字符串，以确保它们完全符合 JSON 规范。

输入项 ​

名称显示名称信息
json_strJSON 字符串要清理的 JSON 字符串。此字符串可以是语言模型或其他来源生成的原始的、可能格式不正确的 JSON 字符串，不一定完全符合 JSON 规范。
remove_control_chars移除控制字符如果设置为 True，则会从 JSON 字符串中移除控制字符（ASCII 字符 0-31 和 127）。这可以帮助消除可能导致解析问题或使 JSON 无效的不可见字符。
normalize_unicode规范化 Unicode当启用时，该选项会将 JSON 字符串中的 Unicode 字符标准化为其规范组合形式（NFC）。这可确保在不同系统中一致地表示 Unicode 字符，并防止字符编码潜在问题。
validate_json验证 JSON如果设置为 True，此选项将尝试解析 JSON 字符串以确保其格式良好，然后再应用最终的修复操作。如果 JSON 无效，则会引发 ValueError，从而允许及早检测 JSON 的主要结构问题。

Outputs ​

NameDisplay NameInfo
outputCleaned JSON String结果为一个经过清理、修复和验证的 JSON 字符串，完全符合 JSON 规范。

输出 ​
