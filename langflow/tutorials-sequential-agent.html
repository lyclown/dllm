顺序任务代理 ​

为多代理应用程序构建一个 顺序任务代理 流，使用多个 Agent（代理）组件。

每个代理都有一个 LLM 模型和一套独特的工具可供使用，Prompt（提示）组件连接到 Agent Instructions（代理指令）字段以控制代理的行为。例如，Researcher Agent（研究员代理）有一个 Tavily AI 搜索 组件作为工具连接。Prompt（提示）指导代理如何回答您的查询，格式化响应，并将查询和研究结果传递给流中的下一个代理。

流中的每个后续代理都基于前一个代理的工作，创建解决复杂问题的推理链。

先决条件 ​

  • 一个 OpenAI API 密钥
  • 一个 Tavily AI API 密钥

打开 Langflow 并创建一个新流程 ​

  1. 点击 New Flow，然后选择 Sequential Tasks Agent。这将打开一个包含运行流程所需组件的起始模板。

顺序任务代理流程由以下组件组成：

  • 代理（Agent） 组件使用连接的LLM（大型语言模型）来分析用户的输入，并在连接的工具中进行选择以完成任务。
  • 聊天输入（Chat Input） 组件接受用户在聊天中的输入。
  • 提示（Prompt） 组件将用户输入与用户定义的提示结合。
  • 聊天输出（Chat Output） 组件将流程的输出打印到聊天窗口。
  • YFinance 工具组件提供从Yahoo Finance获取财务数据的途径。
  • Tavily AI搜索（Tavily AI Search） 工具组件执行由AI驱动的网页搜索。
  • 计算器（Calculator） 工具组件执行数学计算。

运行顺序任务代理流程 ​

  1. 将你的 OpenAI API 密钥添加到**Agent（代理）**组件中。
  2. 将你的 Tavily API 密钥添加到Tavily组件中。
  3. 点击**Playground（操场）**以通过模板的默认问题开始一次聊天会话。

_10               Should I invest in Tesla (TSLA) stock right now?
_10               Please analyze the company's current position, market trends,

这个问题为代理提供了关于如何进行以及回答什么问题的明确指示。

  1. 在Playground（操场）中，检查答案以了解代理如何利用Tavily AI 搜索工具进行查询研究，使用YFinance工具分析股票数据，以及使用计算器判断该股票是否为明智的投资。
  2. 提出类似问题，以观察代理如何利用这些工具回答你的查询。
