Langflow中的嵌入模型 ​

嵌入模型将文本转换为数值向量。这些嵌入捕获了输入文本的语义含义，并允许大型语言模型（LLMs）理解上下文。

请参考您特定组件的文档，以获取更多关于参数的信息。

在流程中使用嵌入模型组件 ​

在这个文档摄取管道的示例中，OpenAI 嵌入模型被连接到一个向量数据库。该组件将文本块转换为向量，并存储在向量数据库中。这些向量化的数据可以用于提供聊天机器人、相似性搜索和代理等人工智能工作负载的信息。

此嵌入组件使用 OpenAI API 密钥进行认证。有关认证的更多信息，请参阅您特定嵌入组件的文档。

VertexAI Embeddings ​

该组件是 Google Vertex AI Embeddings API 的一个封装。

Inputs ​

NameTypeDescription
credentialsCredentials默认的自定义凭据
locationString发起 API 调用时使用的默认位置（默认为：us-central1）
max_output_tokensInteger令牌限制决定了一次提示输出的最大文本量（默认为：128）
