全局变量 ​

全局变量允许您在项目中存储和重用通用的输入值和凭证。您可以在任何显示Globe图标的文本输入字段中使用全局变量。

Langflow 将全局变量存储在其内部数据库中，并使用密钥加密这些值。

创建全局变量 ​

  1. 在 Langflow 用户界面中，点击你的个人资料图标，然后选择 设置。

  2. 点击 全局变量。

  3. 点击 新增。

  4. 在 创建变量 对话框中，在 变量名称 字段中输入你的变量名称。

  5. 可选：为你的全局变量选择一个 类型。可用的类型有 通用（默认）和 凭证。

    不管你选择哪种 类型，Langflow 都会加密全局变量的 值。

  6. 输入你的全局变量的 值。

  7. 可选：使用 应用到字段 菜单，选择一个或多个希望 Langflow 自动应用你的全局变量的字段。例如，如果你选择了 OpenAI API Key，Langflow 会自动将变量应用到任何 OpenAI API Key 字段。

  8. 点击 保存变量。

你现在可以从显示 🌐 图标的任何文本输入字段中选择你的全局变量。

info

由于值是加密的，你无法查看全局变量的实际值。在 设置 > 全局变量 中，值 列会显示 通用 类型变量的加密哈希，对于 凭证 类型变量则不显示任何内容。

编辑全局变量 ​

  1. 在 Langflow 用户界面中，点击你的个人资料图标，然后选择 设置。
  2. 点击 全局变量。
  3. 点击你想要编辑的全局变量。
  4. 在 更新变量 对话框中，你可以编辑以下字段：变量名称、值和 应用于字段。
  5. 点击 更新变量。

删除全局变量 ​

WARNING

删除全局变量会永久删除现有项目中对该变量的任何引用。

  1. 在 Langflow UI 中，点击你的个人资料图标，然后选择 设置。
  2. 点击 全局变量。
  3. 勾选你想要删除的全局变量旁边的复选框。
  4. 点击删除图标。

全局变量以及对它的所有现有引用都会被删除。

添加来自环境的全局变量 ​

自定义环境变量 ​

您可以使用 LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT 环境变量从运行时环境中获取全局变量。

plaintext
# 本地 Docker
- Local
- Docker

如果您在本地安装了 Langflow，您必须在 `.env` 文件中定义 `LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT` 环境变量。

1. 创建一个 `.env` 文件，并使用您喜欢的编辑器打开它。
2. 如下添加 `LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT` 环境变量：

   ```plaintext
   LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT=VARIABLE1,VARIABLE2
1

4

将 VARIABLE1,VARIABLE2 替换为要让 Langflow 从环境中获取的变量列表，变量之间用逗号隔开，不要有空格。例如：my_key,some_string。

  1. 保存并关闭文件。

  2. 使用 .env 文件启动 Langflow：

    plaintext
    VARIABLE1="VALUE1" VARIABLE2="VALUE2" python -m langflow run --env-file .env
    1

    注意
    在此示例中，环境变量 (VARIABLE1="VALUE1" 和 VARIABLE2="VALUE2") 被添加到启动命令前。这是一种在命令行中向 Python 暴露环境变量的基本方法，仅供示例。请确保以适合您环境的最佳方式将环境变量暴露给 Langflow。

  3. 确认 Langflow 成功从环境中获取了全局变量。

    1. 在 Langflow 界面中，点击您的个人资料图标，然后选择 设置。
    2. 点击 全局变量。

    环境变量会在 全局变量 列表中显示。

如果您使用 Docker，可以直接从命令行或 .env 文件传递 LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT。

要从命令行直接传递 LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT：

plaintext
docker run -it --rm \
    -p 7860:7860 \
    -e LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT="VARIABLE1,VARIABLE2" \
    -e VARIABLE1="VALUE1" \
    -e VARIABLE2="VALUE2" \
    langflowai/langflow:latest

INFO

在从环境添加全局变量时，存在以下限制：

  • 你只能从环境中获取名称和值。要添加其他参数，例如应用于字段参数，必须在 Langflow UI 中编辑全局变量。
  • 你从环境中添加的全局变量总是具有凭据类型。
::: tip
如果您想明确阻止 Langflow 从环境中获取全局变量，请在您的 `.env` 文件中将 `LANGFLOW_STORE_ENVIRONMENT_VARIABLES` 设置为 `false`：

### 默认环境变量

Langflow 会自动检测并将某些环境变量转换为 **Credential（凭证）** 类型的全局变量，这些变量被应用于需要它们的组件的特定字段。目前支持以下变量：

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
- `GOOGLE_API_KEY`
- `COHERE_API_KEY`
- `GROQ_API_KEY`
- `HUGGINGFACEHUB_API_TOKEN`
- `SEARCHAPI_API_KEY`
- `SERPAPI_API_KEY`
- `AZURE_OPENAI_API_KEY`
- `AZURE_OPENAI_API_VERSION`
- `AZURE_OPENAI_API_INSTANCE_NAME`
- `AZURE_OPENAI_API_DEPLOYMENT_NAME`
- `AZURE_OPENAI_API_EMBEDDINGS_DEPLOYMENT_NAME`
- `PINECONE_API_KEY`
- `ASTRA_DB_APPLICATION_TOKEN`
- `ASTRA_DB_API_ENDPOINT`
- `UPSTASH_VECTOR_REST_URL`
- `UPSTASH_VECTOR_REST_TOKEN`
- `VECTARA_CUSTOMER_ID`
- `VECTARA_CORPUS_ID`
- `VECTARA_API_KEY`
- `AWS_ACCESS_KEY_ID`
- `AWS_SECRET_ACCESS_KEY`

关于其他环境变量及其使用的信息，请参见 [环境变量](URL)。
