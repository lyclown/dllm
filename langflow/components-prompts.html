Langflow 中的提示组件 ​

提示（Prompt）是输入给语言模型的结构化信息，用于指导模型如何处理用户输入和变量。

提示组件用于创建具有自定义字段和动态变量的提示模板，以便为您的模型提供结构化、可重复的提示。

提示是由自然语言和用大括号 {} 创建的变量组合而成的。

在流程中使用提示组件 ​

在 快速入门 中可以找到修改提示的示例，其中一个基础的聊天机器人流程被扩展为包含完整的向量 RAG（检索增强生成）管道。

Prompt组件中的默认提示是将用户理解为GenAI专家，热情地帮助他们开始构建一些新的东西。

该提示为您的LLM（大语言模型）的聊天互动创建了一个“个性”，但它不包括在模板化提示时可能有用的变量。

要修改提示模板，在Prompt组件中，点击Template字段。例如，{context}变量使LLM模型可以访问嵌入的向量数据，从而提供更好的答案。

Answer the question

当变量被添加到提示模板时，组件中会自动创建新的字段。这些字段可以连接以接收其他组件的文本输入，从而实现提示的自动化，或输出给其他组件指令。控制代理行为的提示示例可以在顺序任务代理入门流程中找到。

Inputs ​

NameDisplay NameInfo
templateTemplate创建一个带有动态变量的提示模板。

Outputs ​

名称显示名称信息
promptPrompt Message由 build_prompt 方法返回的构建提示信息。

Langchain Hub 提示模板 ​

该组件从 Langchain Hub 获取提示。

当加载一个提示时，组件会为自定义变量生成输入字段。例如，默认提示 "efriis/my-first-prompt" 会生成 profession 和 question 的字段。

Inputs ​

NameDisplay NameInfo
langchain_api_keyYour LangChain API Key您的 LangChain API 密钥
langchain_hub_promptLangChain Hub Prompt要使用的 LangChain Hub 提示

输出 ​

名称显示名称信息
prompt构建提示由 `build_prompt` 方法返回的构建提示消息。
