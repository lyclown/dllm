Langflow 中的向量存储组件 ​

向量数据库存储向量数据，支持诸如聊天机器人和增强检索生成（Retrieval Augmented Generation）等 AI 工作负载。

向量数据库组件用于建立与现有向量数据库的连接，或创建内存中的向量存储，以存储和检索向量数据。

向量数据库组件不同于记忆组件，后者专门用于从外部数据库中存储和检索聊天信息。

在流程中使用向量存储组件 ​

此示例使用 Astra DB 向量存储 组件。您的向量存储组件的参数和身份验证方法可能有所不同，但文档导入流程是相同的。文档从本地计算机加载并进行分块。Astra DB 向量存储通过连接的模型组件生成嵌入数据，并将其存储在连接的 Astra DB 数据库中。

然后，可以检索这些向量数据用于诸如“检索增强生成”等工作负载。

用户的聊天输入会被嵌入，并与文档摄取期间嵌入的向量进行相似性搜索比较。结果从向量数据库组件以数据对象的形式输出，并解析为文本。此文本填充在 Prompt 组件中的 context 变量中，该变量用于指导Open AI 模型组件的响应。

或者，可以将向量数据库组件的Retriever（检索器）端口连接到一个retriever tool（检索工具），然后连接到一个agent（代理）组件。这使得代理能将您的向量数据库作为一个工具使用，并基于可用数据做出决策。

Astra DB 矢量存储 ​

该组件使用 Astra DB 实现了具有搜索功能的矢量存储。

有关详细信息，请参阅 DataStax 文档。

Inputs ​

名称显示名称信息
collection_name集合名称Astra DB 内存储向量的集合名称（必填）
tokenAstra DB 应用令牌用于访问 Astra DB 的认证令牌（必填）
api_endpointAPI 端点Astra DB 服务的 API 端点 URL（必填）
search_input搜索输入用于相似性搜索的查询字符串
ingest_data数据导入要导入到向量存储的数据
namespace命名空间Astra DB 中用于集合的可选命名空间
embedding_choice嵌入模型或 Astra Vectorize决定是使用嵌入模型还是 Astra Vectorize 用于集合
embedding嵌入模型允许嵌入模型配置（使用嵌入模型时）
providerVectorize 提供商Astra Vectorize 的提供商（使用 Astra Vectorize 时）
metric度量标准用于向量比较的可选距离度量
batch_size批量大小可选的一次处理的数据批量数
setup_mode设置模式用于设置向量存储的配置模式（选项："Sync"、"Async"、"Off"，默认："Sync"）
pre_delete_collection预删除集合布尔标志，决定在创建新集合之前是否删除现有集合
number_of_results结果数量相似性搜索返回的结果数量（默认：4）
search_type搜索类型所使用的搜索类型（选项："Similarity"、"Similarity with score threshold"、"MMR (Max Marginal Relevance)"）
search_score_threshold搜索分数阈值搜索结果的最低相似性分数阈值
search_filter搜索元数据过滤器可选的用于搜索查询的过滤器字典

输出 ​

名称显示名称信息
vector_store向量存储使用指定参数配置的 Astra DB 向量存储实例。
search_results搜索结果相似性搜索结果，结果为一个包含 Data 对象的列表。

名称显示名称信息

tokenAstra DB Application Token访问 AstraDB 的认证令牌（必需）

search_inputSearch Input相似性搜索的查询字符串

search_score_thresholdSearch Score Threshold搜索结果的最低相似度分数阈值
search_filterSearch Metadata Filter应用于搜索查询的可选过滤字典

search_resultsSearch Results相似性搜索的结果，作为 Data 对象列表。

Vectara RAG ​

此组件利用了 Vectara 的检索增强生成（RAG）功能，根据提供的输入搜索并总结文档。有关更多信息，请参见 Vectara 文档。

Inputs ​

名称类型描述
vectara_customer_idStringVectara 客户 ID
vectara_corpus_idStringVectara 语料库 ID
vectara_api_keySecretStringVectara API 密钥
search_queryString接收回答的查询
lexical_interpolationFloat混合搜索因子（0.005 到 0.1）
filterString用于缩小搜索范围的元数据过滤器
rerankerString重排序器类型（mmr, rerank_multilingual_v1, none）
reranker_kInteger重排序的结果数量（1 到 100）
diversity_biasFloat用于 MMR 重排序器的多样性偏见（0 到 1）
max_resultsInteger用于摘要的最大搜索结果数量（1 到 100）
response_langString响应的语言代码（例如，"eng", "auto"）
promptString用于摘要的提示名称

Outputs ​

NameTypeDescription
answerMessage生成的 RAG（检索增强生成）响应
