Langflow CLI ​

Langflow 命令行界面（Langflow CLI）是管理和运行 Langflow 服务器的主要接口。

CLI命令 ​

以下部分描述了可用的CLI（命令行界面）命令及其选项，以及它们对应的环境变量。

langflow ​

运行 CLI（命令行界面）而不带任何参数时，会显示可用选项和命令的列表。

bash
langflow [OPTIONS]
# 或者
python -m langflow [OPTIONS]
1
2
3

Options ​

选项默认值值描述
--install-completion不适用不适用为当前shell安装自动补全功能。
--show-completion不适用不适用显示自动补全配置文件的位置（如果已安装）。
--help不适用不适用显示关于命令使用及其选项和参数的信息。

langflow api-key ​

如果 [环境变量 LANGFLOW_AUTO_LOGIN] 设置为 true，则为默认超级用户创建一个 API 密钥。

bash
langflow api-key [OPTIONS]
# 或
python -m langflow api-key [OPTIONS]

--install-completion不适用不适用为当前 shell 安装自动补全功能。

langflow copy-db ​

将数据库文件复制到当前目录。
从缓存目录中复制 Langflow 的数据库文件，langflow.db 和 langflow-pre.db（如果存在）到当前目录。

:::note 当前目录是包含 __main__.py 的目录。
你可以通过运行 which langflow 来找到这个目录。 :::

shell
langflow copy-db
# 或
python -m langflow copy-db

选项 ​

选项默认值值类型描述
--testtrue布尔值在测试模式下运行迁移。使用 --no-test 可禁用测试模式。

优先级 ​

Langflow CLI（命令行界面）选项会覆盖对应的环境变量的值。

例如，如果你将环境变量定义为 LANGFLOW_PORT=7860，但使用 CLI 运行时指定了 --port 7880，那么 Langflow 将把端口设置为 7880（即通过 CLI 传递的值）。

赋值 ​

你可以使用两种方式为 CLI（命令行界面）选项赋值。可以在选项标志和值之间以单个空格分隔：--option value。或者，可以使用等号（=）在选项标志和值之间：--option=value。

包含空格的值必须用引号括起来：--option 'Value with Spaces' 或 --option='Value with Spaces'。

Boolean值 ​

布尔选项用于开启或关闭某个行为，因此不接受任何参数。要激活一个布尔选项，请在命令行中输入。 例如：

bash
langflow run --remove-api-keys
1

所有布尔选项都有一个对应的选项用于取反。 例如，--remove-api-keys的取反选项是--no-remove-api-keys。 这些选项允许您取反可能通过环境变量已设置的布尔选项。
