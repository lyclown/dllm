创建问题解决代理 ​

开发 agents（代理） 在 Langchain 中是一个复杂的过程。

AgentComponent 是一个组件，用于轻松创建可以使用您提供的工具来分析任务的 AI 代理。

该组件包含了创建代理所需的所有元素。无需管理 LLM 模型和提供商，只需选择您的模型并输入 API 密钥。无需连接 Prompt（提示） 组件，只需在组件的 Agent Instruction（代理指令） 字段中输入指令。

了解如何从 Tool calling agent（工具调用代理）组件开始构建流程，并查看它如何帮助您解决问题。

前提条件 ​

  • 一个OpenAI API密钥
  • 一个Search API密钥

创建一个使用 AgentComponent 的问题解决代理 ​

在 Langflow 中创建一个问题解决代理，从 工具调用代理 开始。

  1. 点击 新建流程，然后选择 空白流程。
  2. 将一个 Agent 组件点击并拖动到你的工作区。 目前来说，保持默认设置即可，因此本指南假设你正在使用 Open AI 作为 LLM。
  3. 将你的 Open AI API Key 添加到 Agent 组件中。
  4. 在你的流程中添加 聊天输入 和 聊天输出 组件，并将它们连接到工具调用代理。

在连接了一些工具之后，此基本流程使您能够通过Playground与代理进行对话。

  1. 连接Search API工具组件到您的代理。
  2. 将您的Search API 密钥添加到组件。您的代理现在可以查询Search API以获取信息。
  3. 连接一个Calculator工具以解决基本的数学问题。
  4. 将一个API Request组件连接到代理。此组件不属于工具类别，但通过启用Tool Mode，代理仍可以将其用作工具。Tool Mode通过添加一个Toolset端口，可将组件转换为工具，该端口可以连接到代理的工具端口。要在组件上启用Tool Mode，点击Tool Mode。组件的字段会根据所处模式动态变化。

解决代理的问题 ​

您的代理现在拥有执行网络搜索、进行基本数学计算和执行 API 请求的工具。仅凭这些功能，您就可以解决许多问题。

  • 您的桌面游戏小组取消了会议，而您被困在家中。 指向API 请求到一个在线规则文档，告诉您的代理 你是一个使用现有工具的有趣游戏组织者，然后开始玩游戏。

  • 您需要快速学习一门新的软件语言。 指向API 请求到一些文档，告诉您的代理 你是一个使用现有工具的知识渊博的软件开发人员，然后开始学习。

看看您可以用这种流程解决哪些问题。随着问题的专业化程度提高，添加工具。例如，数学代理教程项目添加了一个 Python REPL 组件，以解决对于计算器来说过于复杂的数学问题。

编辑工具的元数据 ​

要编辑工具的元数据，请点击工具中的 编辑工具 按钮以修改其 name（名称）或 description（描述）元数据。这些字段帮助连接的代理（agents，以下均指agent）了解如何使用该工具，而无需修改代理的提示指令。

例如，当启用 工具模式 时，URL 组件提供了三个可用的工具。

工具名称描述
URL-fetch_content使用此工具从 URL 获取并检索原始内容，包括 HTML 和其他结构化数据。返回完整的响应内容。
URL-fetch_content_text使用此工具从网页获取并提取干净、可读的文本内容。仅返回纯文本内容。
URL-as_dataframe使用此工具从 URL 获取结构化数据并将其转换为表格格式。数据以结构化数据框（DataFrame）的形式返回。

连接的代理将根据 name 和 description（描述）元数据清晰了解每个工具的功能。如果您认为代理错误地使用了工具，请编辑工具的元数据来帮助其更好地理解该工具。

工具的名称和描述可以编辑，但默认的工具标识符无法更改。如果您想更改工具标识符，请创建一个自定义组件。

要查看代理正在使用哪些工具以及如何使用它们，请询问代理：你在用什么工具回答我的问题？

使用代理作为工具 ​

代理组件本身也支持工具模式以创建多代理流程。

在您的问题解决流程中添加一个代理，该代理使用不同的OpenAI模型来进行更专业的问题解决。

  1. 点击并拖动一个代理组件到您的工作区。
  2. 将您的Open AI API Key添加到代理组件中。
  3. 在Model Name字段中，选择gpt-4o。
  4. 点击工具模式以使用这个新代理作为一个工具。
  5. 连接新代理的工具集端口到之前创建的代理的工具端口。
  6. 将搜索 API和API 请求连接到新代理。 新代理将使用gpt-4o来执行抓取和搜索信息等需要大上下文窗口的大型任务。 解决问题的代理现在将使用此代理作为一个工具，利用其独特的LLM（大语言模型）和工具集。

  1. 可以编辑新代理的元数据，以帮助问题解决代理理解如何使用它。 点击 **编辑工具 (Edit Tools)** 来修改新代理的 `name` 或 `description` 元数据，以便其用法对问题解决代理来说是清晰的。 例如，默认的工具名称是 `Agent`。将名称编辑为 `Agent-gpt-4o`，并将描述编辑为 `使用 gpt-4o 模型进行复杂问题解决 (Use the gpt-4o model for complex problem solving)`。问题解决代理将理解这是 `gpt-4o` 代理，并将在需要更大上下文窗口的任务中使用它。

添加自定义组件作为工具 ​

代理可以将自定义组件用作工具。

  1. 要将自定义组件添加到问题解决代理流中，点击 New Custom Component。

  2. 向自定义组件添加自定义 Python 代码。以下是用于情感分析的文本分析器示例。

python
from langflow.custom import Component
from langflow.io import MessageTextInput, Output
from langflow.schema import Data
import re

class TextAnalyzerComponent(Component):
    display_name = "Text Analyzer"
    description = "Analyzes and transforms input text."
    documentation: str = "http://docs.langflow.org/components/custom"
    icon = "chart-bar"
    name = "TextAnalyzerComponent"

    inputs = [
        MessageTextInput(
            name="input_text",
            display_name="Input Text",
            info="Enter text to analyze",
            value="Hello, World!",
            tool_mode=True,
        ),
    ]

    outputs = [
        Output(display_name="Analysis Result", name="output", method="analyze_text"),
    ]

    def analyze_text(self) -> Data:
        text = self.input_text

        # 执行文本分析
        word_count = len(text.split())
        char_count = len(text)
        sentence_count = len(re.findall(r'\w+[.!?]', text))

        # 转换文本
        reversed_text = text[::-1]
        uppercase_text = text.upper()

        analysis_result = {
            "original_text": text,
            "word_count": word_count,
            "character_count": char_count,
            "sentence_count": sentence_count,
            "reversed_text": reversed_text,
            "uppercase_text": uppercase_text
        }

        data = Data(value=analysis_result)
        self.status = data
        return data

将任何组件变成工具 ​

如果您想用作工具的组件没有 工具模式 按钮，您可以在该组件的输入中添加 tool_mode=True，并将新的 工具集 输出连接到代理的 工具 输入。

Langflow 支持以下数据类型的 工具模式：

  • DataInput
  • DataFrameInput
  • PromptInput
  • MessageTextInput
  • MultilineInput
  • DropdownInput

例如，上面的 作为工具的组件 示例中，将 tool_mode=True 添加到 MessageTextInput 输入中，以便自定义组件可以用作工具。

python
inputs = [
    MessageTextInput(
        name="input_text",
        display_name="Input Text",
        info="Enter text to analyze",
        value="Hello, World!",
        tool_mode=True,
    ),
]

使用“运行流程”组件作为工具 ​

代理可以使用保存在您工作区中的流程，作为工具，与“运行流程”组件一起使用。

  1. 要添加一个 运行流程 组件，点击并拖动一个 运行流程 组件到您的工作区。
  2. 选择您希望代理使用的流程作为工具。
  3. 在组件中启用 工具模式。
  4. 将工具输出连接到代理的工具输入。
  5. 要启用工具模式，在 运行流程 组件中选择一个 流程，然后点击 工具模式。
  6. 向代理询问，你正在使用什么工具来回答我的问题？ 您的流程应该在响应中可见，作为一个工具。
