环境变量 ​

Langflow 允许您使用环境变量来配置多项设置。

配置环境变量 ​

Langflow 会从以下来源识别支持的环境变量：

  • 你在终端中设置的环境变量。
  • 你通过 Langflow CLI 使用 --env-file 选项从 .env 文件导入的环境变量。

你可以选择只使用一个来源，或者同时使用两个来源。如果选择同时使用两个来源，注意从 .env 文件导入的环境变量相比于在终端中设置的具有优先级。

在终端中设置环境变量 ​

运行以下命令为您当前的终端会话设置环境变量：

  • Linux 或 macOS

    bash
    export VARIABLE_NAME='VALUE'
    1

  • Windows

    bash
    set VARIABLE_NAME='VALUE'
    1

  • Docker

    bash
    docker run -it --rm \
    -p 7860:7860 \
    -e VARIABLE_NAME='VALUE' \
    langflowai/langflow:latest
    1
    2
    3
    4

当您启动 Langflow 时，它会查找在终端中设置的环境变量。如果检测到受支持的环境变量，它会根据优先级规则自动应用指定的值。

从 .env 文件导入环境变量 ​

  1. 创建一个 .env 文件并用您偏好的编辑器打开。

  2. 将您的环境变量添加到文件中：

    bash
    VARIABLE_NAME='VALUE'
VARIABLE_NAME='VALUE'
    1
    2

    提示
    Langflow 项目提供了一个 .env.example 文件，帮助您入门。您可以将此文件的内容复制到您自己的 .env 文件中，并替换示例值为您自己偏好的设置。

  3. 保存并关闭文件。

  4. 启动 Langflow，使用 --env-file 选项来定义您的 .env 文件路径：

在启动时，Langflow 会从您的 .env 文件中导入环境变量，以及您在终端中设置的任何变量，并采用其指定的值。


## 优先级

环境变量在 `.env` 文件中 [定义](#configure-variables-env-file) 的内容优先于在您的 [终端设置](#configure-variables-terminal) 的内容。 这意味着，如果您在终端和 `.env` 文件中设置了相同的环境变量，Langflow 将采用 `.env` 文件中的值。

::: tip CLI优先级
[Langflow CLI 选项](/configuration-cli) 会覆盖 `.env` 文件中定义的以及在终端中设置的对应环境变量的值。
:::

## 支持的环境变量

下表列出了Langflow支持的环境变量。

```markdown
| 变量 | 格式 / 值 | 默认值 | 描述 |
| --- | --- | --- | --- |
| [`DO_NOT_TRACK`](#DO_NOT_TRACK) | `Boolean` | `false` | 如果启用，Langflow 将不会跟踪遥测数据。 |
| [`LANGFLOW_AUTO_LOGIN`](#LANGFLOW_AUTO_LOGIN) | `Boolean` | `true` | 启用 Langflow 的自动登录。设置为 `false` 将禁用自动登录，并需要登录表单以进入 Langflow UI。设置为 `false` 时需要设置 [`LANGFLOW_SUPERUSER`](#LANGFLOW_SUPERUSER) 和 [`LANGFLOW_SUPERUSER_PASSWORD`](https://your-link/environment-variables#LANGFLOW_SUPERUSER_PASSWORD)。 |
| [`LANGFLOW_AUTO_SAVING`](#LANGFLOW_AUTO_SAVING) | `Boolean` | `true` | 启用流的自动保存。参见 [`--auto-saving`](https://your-link/configuration-cli#run-auto-saving) 选项。 |
| [`LANGFLOW_AUTO_SAVING_INTERVAL`](#LANGFLOW_AUTO_SAVING_INTERVAL) | `Integer` | `1000` | 设置流自动保存的间隔时间（以毫秒计）。参见 [`--auto-saving-interval`](https://your-link/configuration-cli#run-auto-saving-interval) 选项。 |
| [`LANGFLOW_BACKEND_ONLY`](#LANGFLOW_BACKEND_ONLY) | `Boolean` | `false` | 仅运行 Langflow 的后端服务器（不含前端）。参见 [`--backend-only`](https://your-link/configuration-cli#run-backend-only) 选项。 |
| [`LANGFLOW_CACHE_TYPE`](#LANGFLOW_CACHE_TYPE) | `async`<br>`redis`<br>`memory`<br>`disk`<br>`critical` | `async` | 设置 Langflow 的缓存类型。如果设置为 `redis`，则必须同时设置以下环境变量：[`LANGFLOW_REDIS_HOST`](#LANGFLOW_REDIS_HOST)、[`LANGFLOW_REDIS_PORT`](#LANGFLOW_REDIS_PORT)、[`LANGFLOW_REDIS_DB`](#LANGFLOW_REDIS_DB) 和 [`LANGFLOW_REDIS_CACHE_EXPIRE`](#LANGFLOW_REDIS_CACHE_EXPIRE)。 |
| [`LANGFLOW_COMPONENTS_PATH`](#LANGFLOW_COMPONENTS_PATH) | `String` | `langflow/components` | 自定义组件所在目录的路径。参见 [`--components-path`](https://your-link/configuration-cli#run-components-path) 选项。 |
| [`LANGFLOW_CONFIG_DIR`](#LANGFLOW_CONFIG_DIR) | `String` | **Linux/WSL**: `~/.cache/langflow/`<br>**macOS**: `/Users/<username>/Library/Caches/langflow/`<br>**Windows**: `%LOCALAPPDATA%\langflow\langflow\Cache` | 设置存储 Langflow 配置文件、日志和数据库的目录。 |
| [`LANGFLOW_DATABASE_URL`](#LANGFLOW_DATABASE_URL) | `String` | 未设置 | 设置 Langflow 的数据库 URL。如果未提供，Langflow 将使用 SQLite 数据库。 |
| [`LANGFLOW_DATABASE_CONNECTION_RETRY`](#LANGFLOW_DATABASE_CONNECTION_RETRY) | `Boolean` | `false` | 如果为 `True`，Langflow 将在连接数据库失败后重试连接。 |
| [`LANGFLOW_DB_POOL_SIZE`](#LANGFLOW_DB_POOL_SIZE) | `Integer` | `10` | **已弃用：**请改用 `LANGFLOW_DB_CONNECTION_SETTINGS`。保持打开的连接池中的连接数量。 |
| [`LANGFLOW_DB_MAX_OVERFLOW`](#LANGFLOW_DB_MAX_OVERFLOW) | `Integer` | `20` | **已弃用：**请改用 `LANGFLOW_DB_CONNECTION_SETTINGS`。允许在连接池大小之外可以打开的连接数量。 |
| [`LANGFLOW_DB_CONNECT_TIMEOUT`](#LANGFLOW_DB_CONNECT_TIMEOUT) | `Integer` | `20` | 在放弃等待锁被释放或与数据库建立连接之前等待的秒数。 |
| [`LANGFLOW_DB_CONNECTION_SETTINGS`](#LANGFLOW_DB_CONNECTION_SETTINGS) | `JSON` | 未设置 | 用于集中数据库连接参数的 JSON 字典。例如：`{"pool_size": 10, "max_overflow": 20}`。 |
| [`LANGFLOW_DEV`](#LANGFLOW_DEV) | `Boolean` | `false` | 在开发模式下运行 Langflow（可能包含错误）。参见 [`--dev`](https://your-link/configuration-cli#run-dev) 选项。 |
| [`LANGFLOW_FALLBACK_TO_ENV_VAR`](#LANGFLOW_FALLBACK_TO_ENV_VAR) | `Boolean` | `true` | 如果启用，当 Langflow 无法获取变量值时，在 Langflow UI 中设置的全球变量将回退到具有相同名称的环境变量。 |
| [`LANGFLOW_FRONTEND_PATH`](#LANGFLOW_FRONTEND_PATH) | `String` | `./frontend` | 前端构建文件所在目录的路径。仅用于开发目的。参见 [`--frontend-path`](https://your-link/configuration-cli#run-frontend-path) 选项。 |
| [`LANGFLOW_HEALTH_CHECK_MAX_RETRIES`](#LANGFLOW_HEALTH_CHECK_MAX_RETRIES) | `Integer` | `5` | 设置健康检查的最大重试次数。参见 [`--health-check-max-retries`](https://your-link/configuration-cli#run-health-check-max-retries) 选项。 |
| [`LANGFLOW_HOST`](#LANGFLOW_HOST) | `String` | `127.0.0.1` | Langflow 服务器将运行的主机。参见 [`--host`](https://your-link/configuration-cli#run-host) 选项。 |
| [`LANGFLOW_LANGCHAIN_CACHE`](#LANGFLOW_LANGCHAIN_CACHE) | `InMemoryCache`<br>`SQLiteCache` | `InMemoryCache` | 要使用的缓存类型。参见 [`--cache`](https://your-link/configuration-cli#run-cache) 选项。 |
| [`LANGFLOW_LOG_LEVEL`](#LANGFLOW_LOG_LEVEL) | `DEBUG`<br>`INFO`<br>`WARNING`<br>`ERROR`<br>`CRITICAL` | `INFO` | 设置 Langflow 的日志记录级别。 |
| [`LANGFLOW_LOG_FILE`](#LANGFLOW_LOG_FILE) | `String` | 未设置 | 日志文件的路径。如果未设置，日志将写入标准输出。 |
| [`LANGFLOW_MAX_FILE_SIZE_UPLOAD`](#LANGFLOW_MAX_FILE_SIZE_UPLOAD) | `Integer` | `100` | 设置上传文件的最大大小（以兆字节为单位）。参见 [`--max-file-size-upload`](https://your-link/configuration-cli#run-max-file-size-upload) 选项。 |
| [`LANGFLOW_MCP_SERVER_ENABLED`](#LANGFLOW_MCP_SERVER_ENABLED) | `Boolean` | `true` | 如果设置为 `False`，Langflow 将不启用 MCP 服务器。 |
| [`LANGFLOW_MCP_SERVER_ENABLE_PROGRESS_NOTIFICATIONS`](#LANGFLOW_MCP_SERVER_ENABLE_PROGRESS_NOTIFICATIONS) | `Boolean` | `false` | 如果设置为 `True`，Langflow 将在 MCP 服务器中发送进度通知。 |
| [`LANGFLOW_NEW_USER_IS_ACTIVE`](#LANGFLOW_NEW_USER_IS_ACTIVE) | `Boolean` | `false` | 启用时，新用户会自动激活，并可以登录而无需超级用户的显式激活。 |
| [`LANGFLOW_OPEN_BROWSER`](#LANGFLOW_OPEN_BROWSER) | `Boolean` | `false` | 在启动时打开系统浏览器。参见 [`--open-browser`](https://your-link/configuration-cli#run-open-browser) 选项。 |
| [`LANGFLOW_PORT`](#LANGFLOW_PORT) | `Integer` | `7860` | Langflow 服务器将运行的端口。如果指定的端口被占用，服务器会自动选择一个空闲端口。参见 [`--port`](https://your-link/configuration-cli#run-port) 选项。 |
| [`LANGFLOW_PROMETHEUS_ENABLED`](#LANGFLOW_PROMETHEUS_ENABLED) | `Boolean` | `false` | 暴露 Prometheus 指标。 |
| [`LANGFLOW_PROMETHEUS_PORT`](#LANGFLOW_PROMETHEUS_PORT) | `Integer` | `9090` | 设置 Langflow 暴露 Prometheus 指标的端口。 |
| [`LANGFLOW_REDIS_CACHE_EXPIRE`](#LANGFLOW_REDIS_CACHE_EXPIRE) | `Integer` | `3600` | 参见 [`LANGFLOW_CACHE_TYPE`](#LANGFLOW_CACHE_TYPE)。 |
| [`LANGFLOW_REDIS_DB`](#LANGFLOW_REDIS_DB) | `Integer` | `0` | 参见 [`LANGFLOW_CACHE_TYPE`](#LANGFLOW_CACHE_TYPE)。 |
| [`LANGFLOW_REDIS_HOST`](#LANGFLOW_REDIS_HOST) | `String` | `localhost` | 参见 [`LANGFLOW_CACHE_TYPE`](#LANGFLOW_CACHE_TYPE)。 |
| [`LANGFLOW_REDIS_PORT`](#LANGFLOW_REDIS_PORT) | `String` | `6379` | 参见 [`LANGFLOW_CACHE_TYPE`](#LANGFLOW_CACHE_TYPE)。 |
| [`LANGFLOW_REMOVE_API_KEYS`](#LANGFLOW_REMOVE_API_KEYS) | `Boolean` | `false` | 从数据库中保存的项目中移除 API 密钥。参见 [`--remove-api-keys`](https://your-link/configuration-cli#run-remove-api-keys) 选项。 |
| [`LANGFLOW_SAVE_DB_IN_CONFIG_DIR`](#LANGFLOW_SAVE_DB_IN_CONFIG_DIR) | `Boolean` | `false` | 将 Langflow 数据库保存在 [`LANGFLOW_CONFIG_DIR`](#LANGFLOW_CONFIG_DIR) 中，而不是在 Langflow 包目录中。注意，当此变量设置为默认值（`false`）时，数据库在不同虚拟环境之间不共享，卸载 Langflow 时，数据库会被删除。 |
| [`LANGFLOW_SECRET_KEY`](#LANGFLOW_SECRET_KEY) | `String` | 自动生成 | 用于加密敏感数据（如 API 密钥）的密钥。如果未提供，将自动生成一个安全密钥。在具有多个实例的生产环境中，应显式设置此项以确保实例之间的一致加密。 |
| [`LANGFLOW_STORE`](#LANGFLOW_STORE) | `Boolean` | `true` | 启用 Langflow Store。参见 [`--store`](https://your-link/configuration-cli#run-store) 选项。 |
| [`LANGFLOW_STORE_ENVIRONMENT_VARIABLES`](#LANGFLOW_STORE_ENVIRONMENT_VARIABLES) | `Boolean` | `true` | 将环境变量存储为数据库中的 [全局变量](https://your-link/configuration-global-variables)。 |
| [`LANGFLOW_SUPERUSER`](#LANGFLOW_SUPERUSER) | `String` | `langflow` | 设置超级用户的名称。如果 [LANGFLOW_AUTO_LOGIN](#LANGFLOW_AUTO_LOGIN) 设置为 `false`，则为必需项。参见 [`superuser --username`](https://your-link/configuration-cli#superuser-username) 选项。 |
| [`LANGFLOW_SUPERUSER_PASSWORD`](#LANGFLOW_SUPERUSER_PASSWORD) | `String` | `langflow` | 设置超级用户的密码。如果 [LANGFLOW_AUTO_LOGIN](#LANGFLOW_AUTO_LOGIN) 设置为 `false`，则为必需项。参见 [`superuser --password`](https://your-link/configuration-cli#superuser-password) 选项。 |
| [`LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT`](#LANGFLOW_VARIABLES_TO_GET_FROM_ENVIRONMENT) | `String` | 未设置 | 逗号分隔的环境变量列表，从环境中获取并存储为 [全局变量](https://your-link/configuration-global-variables)。 |
| [`LANGFLOW_LOAD_FLOWS_PATH`](#LANGFLOW_LOAD_FLOWS_PATH) | `String` | 未设置 | 包含在启动时加载的流 JSON 文件的目录路径。请注意，此功能仅在启用 [`LANGFLOW_AUTO_LOGIN`](#LANGFLOW_AUTO_LOGIN) 时有效。 |
| [`LANGFLOW_WORKER_TIMEOUT`](#LANGFLOW_WORKER_TIMEOUT) | `Integer` | `300` | 工作超时，以秒为单位。参见 [`--worker-timeout`](https://your-link/configuration-cli#run-worker-timeout) 选项。 |
| [`LANGFLOW_WORKERS`](#LANGFLOW_WORKERS) | `Integer` | `1` | 工作进程数量。参见 [`--workers`](https://your-link/configuration-cli#run-workers) 选项。 |
