Langflow 中的内存组件 ​

内存组件通过 session_id 存储和检索聊天消息。

它们与向量存储组件不同，因为它们专为从外部数据库存储和检索聊天消息而构建。

内存组件提供对其各自外部数据库作为内存的访问。这使得大型语言模型（LLMs）或代理能够访问外部内存以实现持久性和上下文保留。

使用内存组件于流程中 ​

此示例流程使用 Astra DB 聊天记忆 组件及 存储消息 和 聊天记忆 组件来存储和检索聊天历史。

存储消息 辅助组件将聊天记忆存储为 数据 对象，而 消息历史 辅助组件则以 数据 对象或字符串的形式检索聊天消息。

AstraDBChatMemory 组件 ​

该组件创建一个 AstraDBChatMessageHistory 实例，用于通过 Astra DB 存储和检索聊天消息。Astra DB 是一种云原生数据库服务。

Inputs ​

NameTypeDescription
collection_nameString用于存储消息的 Astra DB 集合名称。必填。
tokenSecretString用于访问 Astra DB 的认证令牌。必填。
api_endpointSecretStringAstra DB 服务的 API 端点 URL。必填。
namespaceStringAstra DB 中集合的可选命名空间。
session_idMessageText聊天会话 ID。如果未提供，则使用当前会话 ID。

Outputs ​

NameTypeDescription
message_historyBaseChatMessageHistory会话中 AstraDBChatMessageHistory 的一个实例。

CassandraChatMemory 组件 ​

该组件创建一个 CassandraChatMessageHistory 实例，支持使用 Apache Cassandra 或 DataStax Astra DB 存储和检索聊天消息。

输入 ​

名称类型描述
database_refMessageTextCassandra 的连接点或 Astra DB 数据库 ID。必填项。
usernameMessageTextCassandra 的用户名（Astra DB 可留空）。
tokenSecretStringCassandra 的密码或 Astra DB 的令牌。必填项。
keyspaceMessageTextCassandra 的键空间或 Astra DB 的命名空间。必填项。
table_nameMessageText用于存储消息的表或集合名称。必填项。
session_idMessageText聊天会话的唯一标识符。可选项。
cluster_kwargsDictionaryCassandra 集群配置的其他关键字参数。可选项。

输出 ​

名称类型描述
message_historyBaseChatMessageHistory一个用于会话的 CassandraChatMessageHistory 实例。

Mem0 Chat Memory ​

Mem0 Chat Memory 组件使用 Mem0 内存存储来检索和存储聊天消息。

Inputs ​

名称显示名称信息
mem0_configMem0 配置用于初始化 Mem0 内存实例的配置字典。
ingest_message要导入的消息要导入到 Mem0 内存中的消息内容。
existing_memory现有内存实例可选的现有 Mem0 内存实例。
user_id用户 ID与消息相关的用户标识符。
search_query搜索查询用于在 Mem0 中搜索相关记忆的输入文本。
mem0_api_keyMem0 API 密钥Mem0 平台的 API 密钥（若使用本地版本请留空）。
metadata元数据要与导入消息相关联的附加元数据。
openai_api_keyOpenAI API 密钥OpenAI 的 API 密钥。如果使用 OpenAI 嵌入而没有提供相应配置，则需要此项。

输出 ​

名称显示名称信息
memoryMem0 Memory处理数据后生成的 Mem0 Memory 对象。
search_results搜索结果查询 Mem0 memory 后的搜索结果。

ZepChatMemory 组件 ​

该组件创建一个 ZepChatMessageHistory 实例，使得可以使用 Zep（大型语言模型的内存服务器）来存储和检索聊天消息。

输入 ​

名称类型描述
urlMessageTextZep 实例的 URL。必填。
api_keySecretString用于与 Zep 实例进行身份验证的 API 密钥。
api_base_pathDropdown要使用的 API 版本。选项："api/v1" 或 "api/v2"。
session_idMessageText聊天会话的唯一标识符。可选。

Outputs ​

NameTypeDescription
message_historyBaseChatMessageHistoryZepChatMessageHistory类的一个实例用于当前会话。
