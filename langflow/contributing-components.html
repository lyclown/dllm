Contribute components ​

新组件是作为 CustomComponent 类的对象添加的。

任何依赖项都会被添加到 pyproject.toml 文件中。

为 Langflow 贡献一个示例组件 ​

任何人都可以贡献一个示例组件。例如，如果你创建了一个新的文档加载器 MyCustomDocumentLoader，你可以按照以下步骤将其贡献给 Langflow。

  1. 将你的加载器写成 CustomComponent 类的一个对象。你将创建一个新的类，MyCustomDocumentLoader，该类将继承自 CustomComponent 并覆盖基类的方法。

  2. 定义可选属性如 display_name、description 和 documentation，以便提供关于你的自定义组件的信息。

  3. 实现 build_config 方法，以定义你的自定义组件的配置选项。

  4. 实现 build 方法，定义使用 build_config 方法中指定的输入参数并返回期望输出的逻辑。

  5. 将代码添加到 components/documentloaders 文件夹中。

  6. 将依赖添加到 documentloaders/__init__.py 中，如 from .MyCustomDocumentLoader import MyCustomDocumentLoader。

  7. 将任何新的依赖项添加到 pyproject.toml 文件中。

  8. 为你的组件提交文档。对于这个示例，你需要将文档提交到 loaders 页面。

  9. 提交 Pull Request 请求你的更改。Langflow 团队将会查看，提出建议，然后将你的组件添加到 Langflow 中。
