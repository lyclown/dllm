Langflow 中的代理组件 ​

代理组件定义了在流中AI代理的行为和能力。

代理使用大型语言模型（LLMs）作为推理引擎，以决定使用哪个连接的工具组件来解决问题。

在代理功能中的工具基本上是代理可以调用以执行任务或访问外部资源的函数。一个函数会被封装成一个 Tool（工具）对象，并具有代理能够理解的通用接口。代理通过工具注册来获知工具，即在代理初始化时提供可用工具的列表。Tool 对象的描述告诉代理该工具可以做什么。

然后，代理使用连接的LLM来对问题进行推理，以决定哪个工具是最适合该任务的。

在流程中使用代理 ​

简单代理入门项目使用连接到 URL 和计算器工具的代理组件来回答用户的问题。OpenAI LLM 作为代理的大脑，决定使用哪个工具。工具通过Tools端口连接到代理组件。

对于多代理示例，请参见创建一个解决问题的代理。

Agent 组件 ​

该组件创建一个代理，可以使用工具根据给定指令回答问题并执行任务。

该组件包括一个 LLM 模型集成、一个系统消息提示，以及一个 Tools（工具）端口用于连接工具以扩展其功能。

欲了解关于此组件的更多信息，请参阅 工具调用代理文档。

Inputs ​

名称类型描述
agent_llmDropdown语言模型的提供商，代理将使用该模型生成响应。选项包括 OpenAI 和其他提供商，或自定义。
system_promptString系统提示：用于指导代理行为的初始指令和上下文。
toolsList代理可用的工具列表。
input_valueString代理处理的输入任务或问题。
add_current_date_toolBoolean如果为 true，添加一个返回当前日期的工具给代理。
memoryMemory可选的内存配置，用于维护对话历史记录。
max_iterationsInteger代理可以执行的最大迭代次数。
handle_parsing_errorsBoolean是否在代理执行过程中处理解析错误。
verboseBoolean启用详细输出以进行详细日志记录。

Outputs ​

名称类型描述
responseMessage代理程序对给定输入任务的响应。

CrewAI Agent ​

该组件代表CrewAI的一个Agent（代理），允许在一个团队中创建具有定义的角色、目标和能力的专业AI代理。

欲了解更多信息，请参阅 CrewAI 文档。

Inputs ​

名称显示名称信息
roleRole代理的角色
goalGoal代理的目标
backstoryBackstory代理的背景故事
toolsTools代理可使用的工具
llmLanguage Model运行代理的语言模型
memoryMemory代理是否应该拥有记忆
verboseVerbose启用详细输出
allow_delegationAllow Delegation代理是否被允许将任务委派给其他代理
allow_code_executionAllow Code Execution代理是否被允许执行代码
kwargskwargs为代理提供的附加关键字参数

Outputs ​

NameDisplay NameInfo
outputAgentThe constructed CrewAI Agent object

Hierarchical Crew ​

该组件代表一组代理，负责管理他们在层次结构中的协作方式和应执行的任务。该组件允许创建一个团队，由经理监督任务执行。

欲了解更多信息，请参见 CrewAI 文档。

Inputs ​

名称显示名称信息
agentsAgents表示团队成员的 Agent 对象列表
tasksTasks表示要执行任务的 HierarchicalTask 对象列表
manager_llmManager LLM管理代理的语言模型（可选）
manager_agentManager Agent作为管理者的特定代理（可选）
verboseVerbose启用详细输出以进行详细日志记录
memoryMemory指定团队的内存配置
use_cacheUse Cache启用结果缓存
max_rpmMax RPM设置每分钟的最大请求数
share_crewShare Crew决定是否在代理之间共享团队信息
function_calling_llmFunction Calling LLM为函数调用指定的语言模型

Outputs ​

名称显示名称信息
crewCrew构建的 Crew 对象，具备层级任务执行功能
