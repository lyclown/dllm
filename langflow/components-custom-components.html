创建自定义 Python 组件 ​

自定义组件是在 Langflow 中创建的，它使用自定义、可重用的 Python 代码扩展了平台的功能。

由于 Langflow 在后台使用 Python 运行，你可以在自定义组件中实现任何 Python 函数。这意味着你可以利用诸如 Pandas、Scikit-learn、Numpy 以及成千上万的其他库的强大功能来创建处理数据的组件，并以无限多样的方式进行数据处理。你可以使用任何类型，只要在输出方法中进行了正确的类型注释（例如，> list[int]）。

自定义组件创建了可重用且可配置的组件，以增强 Langflow 的功能，使其成为在用户与 AI 消息之间进行复杂处理的强大工具。

目录结构要求 ​

默认情况下，Langflow 会在 langflow/components 目录中查找自定义组件。

如果你使用 LANGFLOW_COMPONENTS_PATH 环境变量在不同位置创建自定义组件，组件必须按照特定的目录结构组织，以便在界面上正确加载和显示：

plaintext
/your/custom/components/path/    # 基本目录（由 LANGFLOW_COMPONENTS_PATH 设置）
    └── category_name/          # 必需的分类子文件夹（决定菜单名称）
        └── custom_component.py # 组件文件
1
2
3

组件必须放置在 分类文件夹 内，而不是直接放在基本目录中。分类文件夹的名称决定了组件在用户界面菜单中的显示位置。

例如，要将组件添加到 Helpers 菜单中，请将其放入 helpers 子文件夹中：

plaintext
/app/custom_components/          # LANGFLOW_COMPONENTS_PATH
    └── helpers/                 # 显示为“Helpers”菜单
        └── custom_component.py  # 你的组件

你可以拥有 多个分类文件夹 来将组件组织到不同的菜单中：

/app/custom_components/
    ├── helpers/
    │   └── helper_component.py
    └── tools/
        └── tool_component.py

创建 Langflow 中的自定义组件 ​

在 Langflow 中创建自定义组件涉及到创建一个定义组件功能、输入和输出的 Python 类。默认代码为您的自定义组件提供了一个工作结构。

python
# 从 langflow.field_typing 模块引入 Data
from langflow.custom import Component
from langflow.io import MessageTextInput, Output
from langflow.schema import Data

class CustomComponent(Component):
    display_name = "Custom Component"
    description = "使用此模板创建您自己的组件。"
    documentation: str = "https://docs.langflow.org/components-custom-components"
    icon = "custom_components"
    name = "CustomComponent"

    inputs = [
        MessageTextInput(name="input_value", display_name="输入值", value="Hello, World!"),
    ]

    outputs = [
        Output(display_name="输出", name="output", method="build_output"),
    ]

    def build_output(self) -> Data:
        data = Data(value=self.input_value)
        self.status = data
        return data

添加输入并修改输出方法 ​

该代码定义了一个自定义组件，该组件接受 5 个输入并输出一个消息。

将其复制并粘贴到自定义组件代码窗格中，然后点击 检查并保存。

python
from langflow.custom import Component
from langflow.inputs import StrInput, MultilineInput, SecretStrInput, IntInput, DropdownInput
from langflow.template import Output, Input
from langflow.schema.message import Message

class MyCustomComponent(Component):
    display_name = "我的自定义组件"
    description = "一个具有各种输入类型的自定义组件示例。"

    inputs = [
        StrInput(
            name="username",
            display_name="用户名",
            info="输入您的用户名。"
        ),
        SecretStrInput(
            name="password",
            display_name="密码",
            info="输入您的密码。"
        ),
        MessageTextInput(
            name="special_message",
            display_name="特别信息",
            info="输入一条特别的信息。",
        ),
        IntInput(
            name="age",
            display_name="年龄",
            info="输入您的年龄。"
        ),
        DropdownInput(
            name="gender",
            display_name="性别",
            options=["男性", "女性", "其他"],
            info="选择您的性别。"
        )
    ]

    outputs = [
        Output(display_name="结果", name="result", method="process_inputs"),
    ]

    def process_inputs(self) -> Message:
        """
        处理用户输入并返回一个 Message 对象。

        返回:
            Message: 包含处理信息的 Message 对象。
        """
        try:
            processed_text = f"用户 {self.username} (年龄: {self.age}, 性别: {self.gender}) " \
                             f"发送了以下特别信息: {self.special_message}"
            return Message(text=processed_text)
        except AttributeError as e:
            return Message(text=f"处理输入时出错: {str(e)}")

输入类型 ​

Langflow 提供了几种更高级的输入类型，以简化自定义组件的创建。这些输入类型标准化了输入的定义、验证和使用方式。以下是这些输入的使用指南及其主要目的：

HandleInput ​ ​

表示一个输入，它具有指向特定类型（例如，BaseLanguageModel、BaseRetriever等）的句柄。

  • 用法： 用于在流程中连接到特定组件类型。

DataInput ​

表示一个接收 Data（数据）对象的输入。

  • 用法： 适用于处理或操作数据对象的组件。
  • 输入类型： ["Data"]

StrInput ​

表示一个标准的字符串输入字段。

  • 用途： 用于用户需要提供文本的任何输入。
  • 输入类型： ["Text"]

MessageInput ​

表示专门用于 Message（消息）对象的输入字段。

  • 用法： 用于处理或处理消息的组件中。
  • 输入类型： ["Message"]

MessageTextInput ​

表示用于消息的文本输入。

  • 使用方法： 适用于需要从消息对象中提取文本的组件。
  • 输入类型： ["Message"]

MultilineInput ​

表示支持多行的文本字段。

  • 用法： 适合需要用户编写较长文本的输入场景。
  • 输入类型： ["Text"]
  • 属性： multiline=True

SecretStrInput^ ​

表示一个密码输入字段。

  • 用法： 用于需要隐藏输入的敏感文本输入（例如，密码、API 密钥）。
  • 属性： password=True
  • 输入类型： 不接受输入类型，意味着它没有用于与前一个节点/组件连接的输入接口。

IntInput ​

表示一个整数输入字段。

  • 用法： 用于数值输入，该数值应为整数。
  • 输入类型： ["Integer"]

FloatInput ​

表示一个浮点型输入字段。

  • 用法： 用于数值输入，值应为浮点数。
  • 输入类型： ["Float"]

BoolInput ​

表示一个布尔输入字段。

  • 用法： 用于真/假或是/否类型的输入。
  • 输入类型： ["Boolean"]

NestedDictInput ​

表示用于嵌套字典的输入字段。

  • 用法： 用于复杂数据结构，输入需要是一个字典。
  • 输入类型： ["NestedDict"]

DictInput ​

代表一个用于字典的输入字段。

  • 用法： 适用于需要字典格式的输入。
  • 输入类型： ["Dict"]

DropdownInput ​

表示一个下拉输入字段。

  • 用法： 用于需要用户从预定义选项列表中进行选择的场合。
  • 属性： options 用于定义可选的选项列表。
  • 输入类型： ["Text"]

FileInput ​

表示一个文件输入字段。

  • 用法： 用于上传文件。
  • 属性： file_types 用于指定可以上传的文件类型。
  • 输入类型： ["File"]

通用输入 ​

Langflow 提供本地输入类型，但只要在输出方法中正确注释（例如，-> list[int]），您可以使用任何类型。

Input类高度可定制，允许您为每个输入字段指定各种属性。它有多个可以自定义的属性：

  • field_type: 指定字段的类型（例如，str（字符串），int（整数））。默认值为 str。
  • required: 布尔值，指示字段是否为必填项。默认值为 False。
  • placeholder: 输入字段的占位符文本。默认值为空字符串。
  • is_list: 布尔值，指示字段是否应该接受一个值列表。默认值为 False。
  • show: 布尔值，指示字段是否应显示。默认值为 True。
  • multiline: 布尔值，指示字段是否允许多行输入。默认值为 False。
  • value: 输入字段的默认值。默认值为 None。
  • file_types: 接受的文件类型列表（针对文件输入）。默认值为空列表。
  • file_path: 如果字段是文件输入，则为文件路径。默认值为 None。
  • password: 布尔值，指示字段是否为密码。默认值为 False。
  • options: 字段的可选项列表（用于下拉菜单）。默认值为 None。
  • name: 输入字段的名称。默认值为 None。
  • display_name: 输入字段的显示名称。默认值为 None。
  • advanced: 布尔值，指示字段是否为高级参数。默认值为 False。
  • input_types: 接受的输入类型列表。默认值为 None。
  • dynamic: 布尔值，指示字段是否是动态的。默认值为 False。
  • info: 输入字段的附加信息或工具提示。默认值为空字符串。
  • real_time_refresh: 布尔值，指示字段是否应实时刷新。默认值为 None。
  • refresh_button: 布尔值，指示字段是否应有刷新按钮。默认值为 None。
  • refresh_button_text: 刷新按钮的文本。默认值为 None。
  • range_spec: 数字字段的范围规范。默认值为 None。
  • load_from_db: 布尔值，指示字段是否应从数据库加载。默认值为 False。
  • title_case: 布尔值，指示显示名称是否应为标题大小写。默认值为 True。

创建一个带有通用输入的自定义组件 ​

以下是如何使用 Input 类为组件定义输入的示例。

将其复制并粘贴到自定义组件代码窗格中，然后点击 检查并保存。

python
from langflow.template import Input, Output
from langflow.custom import Component
from langflow.field_typing import Text
from langflow.schema.message import Message
from typing import Dict, Any

class TextAnalyzerComponent(Component):
    display_name = "文本分析器"
    description = "分析输入文本并提供基本统计数据。"

    inputs = [
        Input(
            name="input_text",
            display_name="输入文本",
            field_type="Message",
            required=True,
            placeholder="输入要分析的文本",
            multiline=True,
            info="您想要分析的文本。",
            input_types=["Text"]
        ),
        Input(
            name="include_word_count",
            display_name="包含字数统计",
            field_type="bool",
            required=False,
            info="是否在分析中包含字数统计。",
        ),
        Input(
            name="perform_sentiment_analysis",
            display_name="执行情感分析",
            field_type="bool",
            required=False,
            info="是否执行基本的情感分析。",
        ),
    ]

    outputs = [
        Output(display_name="分析结果", name="results", method="analyze_text"),
    ]

    def analyze_text(self) -> Message:
        # 从 Message 对象提取文本
        if isinstance(self.input_text, Message):
            text = self.input_text.text
        else:
            text = str(self.input_text)

        results = {
            "character_count": len(text),
            "sentence_count": text.count('.') + text.count('!') + text.count('?')
        }

        if self.include_word_count:
            results["word_count"] = len(text.split())

        if self.perform_sentiment_analysis:
            # 基本情感分析
            text_lower = text.lower()
            if "happy" in text_lower or "good" in text_lower:
                sentiment = "positive"
            elif "sad" in text_lower or "bad" in text_lower:
                sentiment = "negative"
            else:
                sentiment = "neutral"

            results["sentiment"] = sentiment

        # 将结果字典转换为格式化字符串
        formatted_results = "\n".join([f"{key}: {value}" for key, value in results.items()])

        # 返回一个 Message 对象
        return Message(text=formatted_results)

# 定义如何使用输入和输出
component = TextAnalyzerComponent()

创建具有多个输出的自定义组件 ​

在 Langflow 中，自定义组件可以有多个输出。每个输出可以与组件中的特定方法关联，使您能够为每个输出路径定义不同的行为。当您想根据某些条件路由数据或以多种方式处理数据时，此功能特别有用。

  1. 输出的定义：每个输出都在组件的 outputs 列表中定义。每个输出都与一个显示名称、一个内部名称以及一个用于生成输出的方法相关联。

  2. 输出方法：与输出相关联的方法负责生成该特定输出的数据。当组件执行时，这些方法被调用，每个方法都可以独立生成其结果。

这个示例组件有两个输出：

  • process_data: 处理输入文本（例如，将其转换为大写字母）并返回结果。
  • get_processing_function: 返回 process_data 方法本身，以便在组合中重复使用。
python
from typing import Callable
from langflow.custom import Component
from langflow.inputs import StrInput
from langflow.template import Output
from langflow.field_typing import Text

class DualOutputComponent(Component):
    display_name = "Dual Output"
    description = "处理输入文本并返回处理结果和处理函数本身。"
    icon = "double-arrow"

    inputs = [
        StrInput(
            name="input_text",
            display_name="输入文本",
            info="需要处理的文本输入。",
        ),
    ]

    outputs = [
        Output(display_name="Processed Data", name="processed_data", method="process_data"),
        Output(display_name="Processing Function", name="processing_function", method="get_processing_function"),
    ]

    def process_data(self) -> Text:
        # 处理输入文本（例如，转换为大写）
        processed = self.input_text.upper()
        self.status = processed
        return processed

    def get_processing_function(self) -> Callable[[], Text]:
        # 返回处理函数本身
        return self.process_data

此示例展示了如何在自定义组件中定义多个输出。第一个输出返回处理后的数据，而第二个输出返回处理函数本身。

processing_function 输出可在需要函数本身用于进一步处理或动态流控制的场景中使用。注意，两个输出都已正确注释其各自的类型，从而确保了清晰度和类型安全。

特殊操作 ​

高级方法和属性提供了额外的控制和功能。了解如何利用这些功能可以增强自定义组件的能力。

  • self.inputs: 访问所有定义的输入。当输出方法需要与多个输入交互时非常有用。

  • self.outputs: 访问所有定义的输出。当一个输出函数需要触发另一个输出函数时，这一点特别有用。

  • self.status: 使用此属性更新组件的状态或中间结果。它有助于跟踪组件的内部状态或存储临时数据。

  • self.graph.flow_id: 获取流程 ID，对于维护上下文或调试很有用。

  • self.stop("output_name"): 在输出函数中使用此方法可以防止数据通过其他组件发送。此方法会停止下一个组件的执行，特别适用于在基于特定条件时需要阻止组件运行的特定操作。
