安装 Langflow ​

您可以将 Langflow 部署在本地，或者使用 Datastax Langflow 作为托管服务。

安装 Langflow 到本地 ​

可以通过 uv（推荐）、pip、或 pipx 将 Langflow 安装到本地。

前置条件 ​

  • 安装 Python 3.10 到 3.12
  • 安装 uv、pip、或 pipx
  • 在安装 Langflow 之前，我们建议使用 uv、venv、或 conda 创建一个虚拟环境来隔离你的 Python 依赖项

使用 pip 或 pipx 安装 Langflow ​

安装带有 uv 的 Langflow：

shell
uv pip install langflow
1

使用 pip 安装 Langflow：

shell
python -m pip install langflow
1

使用 pipx 并指定 Python 3.10 可执行文件来安装 Langflow：

shell
pipx install langflow --python python3.10
1

运行 Langflow ​

  1. 要使用 uv 运行 Langflow，输入以下命令。

    bash
    uv run langflow run
    1

  2. 要使用 pip 运行 Langflow，输入以下命令。

    bash
    python -m langflow run
    1

  3. 确认本地 Langflow 实例已启动，打开 Chromium 内核浏览器访问 http://127.0.0.1:7860。

现在 Langflow 已经运行，接下来请参阅快速开始以创建您的第一个 flow。

管理 Langflow 版本 ​

要使用 uv 命令将 Langflow 升级到最新版本，请使用 uv pip 升级命令。

bash
uv pip install langflow -U
1

要将 Langflow 升级到最新版本，请使用 pip 升级命令。

bash
python -m pip install langflow -U
1

要安装特定版本的 Langflow 包，请在命令中添加所需版本。

bash
python -m pip install langflow==1.1
1

要重新安装 Langflow 及其所有依赖项，请在命令中添加 --force-reinstall 标志。

bash
python -m pip install langflow --force-reinstall
1

DataStax Langflow ​

DataStax Langflow 是托管版的Langflow，与 Astra DB 集成。无需安装或设置，只需几分钟即可启动并运行。 免费注册。

常见安装问题 ​

这是安装和运行 Langflow 时可能遇到的问题清单。

No langflow.__main__ 模块 ​

当你尝试使用命令 langflow run 运行 Langflow 时，会遇到以下错误：

plaintext
> No module named 'langflow.__main__'
1
  1. 请运行 python -m langflow run，而不是 langflow run。
  2. 如果这不起作用，请使用 python -m pip install langflow -U 重新安装最新版本的 Langflow。
  3. 如果仍然无效，请使用 python -m pip install langflow --pre -U --force-reinstall 重新安装 Langflow 及其依赖项。

Langflow runTraceback ​

当你尝试使用命令 langflow run 运行 Langflow 时，会遇到以下错误：

shell
> langflow runTraceback (most recent call last): File ".../langflow", line 5, in <module>  from langflow.__main__ import mainModuleNotFoundError: No module named 'langflow.__main__'
1

此错误可能有两个原因：

  1. 你通过 pip install langflow 安装了 Langflow，但系统中已经安装了以前版本的 Langflow。在这种情况下，你可能运行了错误的可执行文件。为了解决这个问题，请运行正确的可执行文件，使用命令 python -m langflow run 替代 langflow run。如果这不起作用，尝试卸载并重新安装 Langflow，使用 python -m pip install langflow --pre -U。

  2. 在安装过程中可能发生了一些版本冲突。运行 python -m pip install langflow --pre -U --force-reinstall 以重新安装 Langflow 及其依赖项。

运行迁移时出错 ​

10 > Something went wrong running migrations. Please, run 'langflow migration --fix'
1

清除缓存可以通过删除缓存文件夹的内容来实现。

此文件夹的位置如下：

  • Linux 或 Windows 上的 WSL2: home/<用户名>/.cache/langflow/
  • MacOS: /Users/<用户名>/Library/Caches/langflow/

这个错误可能发生在 Langflow 升级时，由于新版本无法覆盖 .cache/langflow/ 中的 langflow-pre.db 文件。清除缓存会移除该文件，但同时也会清除您的设置。

如果您希望保留文件，请在清除文件夹之前备份。

Langflow安装在pip依赖解析时冻结 ​

使用 pip install langflow 进行Langflow安装时会缓慢失败，并出现以下错误信息：

plaintext
pip is looking at multiple versions of <<library>> to determine which version is compatible with other requirements. This could take a while.
1

要解决此问题，请使用 uv 来代替 pip 安装Langflow。

plaintext
uv pip install langflow
1

要使用uv运行Langflow：

plaintext
uv run langflow run
1
