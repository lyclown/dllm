API 密钥 ​

Langflow 提供了 API 密钥功能，使用户能够在无需传统登录认证的情况下访问个人组件和流。API 密钥是用户特定的令牌，可以包含在请求头、查询参数或作为命令行参数以认证 API 调用。本文件概述了如何在 Langflow 中生成、使用和管理 API 密钥。

INFO

默认的用户和密码通过 LANGFLOW_SUPERUSER 和 LANGFLOW_SUPERUSER_PASSWORD 环境变量设置。默认值分别是 langflow 和 langflow。

生成 API 密钥 ​

生成一个特定用户的令牌以供 Langflow 使用。

通过Langflow UI生成API密钥 ​

  1. 点击你的用户图标并选择 设置。
  2. 点击 Langflow API，然后点击 添加新密钥。
  3. 为你的密钥命名，然后点击 创建密钥。
  4. 复制API密钥并存储在一个安全的位置。

使用 Langflow CLI 生成 API 密钥 ​

shell
langflow api-key
# 或
python -m langflow api-key

使用 Langflow API 密钥认证请求 ​

在 API 请求中包含您的 API 密钥，以便对 Langflow 的请求进行认证。

在 HTTP 头中包含 API 密钥 ​

要在使用 cURL 进行 API 请求时使用 API 密钥，请在 HTTP 头中包含 API 密钥。

bash
curl -X POST \
  "http://127.0.0.1:7860/api/v1/run/*`YOUR_FLOW_ID`*?stream=false" \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: *`YOUR_API_KEY`*' \
  -d '{"inputs": {"text":""}, "tweaks": {}}'

要在使用 Python 的 requests 库进行 API 请求时使用 API 密钥，请将 API 密钥作为变量字符串包含进去。

python
import argparse
import json
from argparse import RawTextHelpFormatter
import requests
from typing import Optional
import warnings

try:
    from langflow.load import upload_file
except ImportError:
    warnings.warn("Langflow 提供一个函数来帮助您将文件上传至流程。请安装 langflow 以便使用。")
    upload_file = None

BASE_API_URL = "http://127.0.0.1:7860"
FLOW_ID = "*`YOUR_FLOW_ID`*"
ENDPOINT = ""  # 您可以在流程设置中指定具体的端点名称

# 您可以通过添加 tweaks 字典来调整流程
# 例如 {"OpenAI-XXXXX": {"model_name": "gpt-4"}}
TWEAKS = {
  "ChatInput-8a86T": {},
  "Prompt-pKfl9": {},
  "ChatOutput-WcGpD": {},
  "OpenAIModel-5UyvQ": {}
}

def run_flow(message: str,
  endpoint: str,
  output_type: str = "chat",
  input_type: str = "chat",
  tweaks: Optional[dict] = None,
  api_key: Optional[str] = None) -> dict:
    """
    运行一个流程，使用给定的消息和可选的 tweaks。

    :param message: 要发送到流程的消息
    :param endpoint: 流程的 ID 或端点名称
    :param tweaks: 可选的 tweaks 来自定义流程
    :return: 来自流程的 JSON 响应
    """
    api_url = f"{BASE_API_URL}/api/v1/run/{endpoint}"

    payload = {
        "input_value": message,
        "output_type": output_type,
        "input_type": input_type,
    }
    headers = None
    if tweaks:
        payload["tweaks"] = tweaks
    if api_key:
        headers = {"x-api-key": api_key}
    response = requests.post(api_url, json=payload, headers=headers)
    return response.json()

def main():
    parser = argparse.ArgumentParser(description="""运行一个流程，使用给定的消息和可选的 tweaks。
像这样运行它: python <your file>.py "your message here" --endpoint "your_endpoint" --tweaks '{"key": "value"}'""",
        formatter_class=RawTextHelpFormatter)
    parser.add_argument("message", type=str, help="要发送到流程的消息")
    parser.add_argument("--endpoint", type=str, default=ENDPOINT or FLOW_ID, help="流程的 ID 或端点名称")
    parser.add_argument("--tweaks", type=str, help="表示自定义流程的 tweaks 的 JSON 字符串", default=json.dumps(TWEAKS))
    parser.add_argument("--api_key", type=str, help="用于认证的 API 密钥", default=None)
    parser.add_argument("--output_type", type=str, default="chat", help="输出类型")
    parser.add_argument("--input_type", type=str, default="chat", help="输入类型")
    parser.add_argument("--upload_file", type=str, help="要上传的文件路径", default=None)
    parser.add_argument("--components", type=str, help="要将文件上传至的组件", default=None)

    args = parser.parse_args()
    try:
      tweaks = json.loads(args.tweaks)
    except json.JSONDecodeError:
      raise ValueError("无效的 tweaks JSON 字符串")

    if args.upload_file:
        if not upload_file:
            raise ImportError("未安装 Langflow。请安装它以使用 upload_file 函数。")
        elif not args.components:
            raise ValueError("您需要提供要将文件上传至的组件。")
        tweaks = upload_file(file_path=args.upload_file, host=BASE_API_URL, flow_id=args.endpoint, components=[args.components], tweaks=tweaks)

    response = run_flow(
        message=args.message,
        endpoint=args.endpoint,
        output_type=args.output_type,
        input_type=args.input_type,
        tweaks=tweaks,
        api_key=args.api_key
    )

    print(json.dumps(response, indent=2))

if __name__ == "__main__":
    main()

安全注意事项 ​

  • 可见性: 出于安全原因，API 密钥无法通过用户界面(UI)再次检索。
  • 范围: 该密钥仅允许访问已发布给特定用户的流程和组件。

自定义 API 端点 ​

要为您的 API 端点选择一个自定义名称，选择 项目设置 > 端点名称，然后为您的端点命名。

撤销 API 密钥 ​

要撤销 API 密钥，请从设置菜单中的密钥列表中删除它。

  1. 点击您的用户图标并选择设置。
  2. 点击Langflow API。
  3. 选择您想要删除的密钥并点击垃圾桶图标。

此操作会立即使该密钥无效，并阻止其再次使用。
