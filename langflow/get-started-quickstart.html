快速入门 ​

通过构建一个基于OpenAI的聊天机器人应用来了解Langflow。在构建完聊天机器人后，添加检索增强生成（Retrieval Augmented Generation，RAG），以便使用自己的数据进行聊天。

前提条件 ​

  • OpenAI API 密钥
  • Astra DB 向量数据库 ，包括：
    • AstraDB 应用令牌
    • Astra 中的一个集合

打开 Langflow 并开始一个新项目 ​

  1. 在 Langflow 仪表板中，点击 New Flow，然后选择 Blank Flow。此时会打开一个空白工作区，您可以在这里构建您的流程。

TIP

如果您不想创建一个空白流程，可以点击 New Flow，然后选择 Basic Prompting 来启动一个预构建的流程。 继续前往运行基本提示流程。

  1. 选择 Basic Prompting。

  2. Basic Prompting 流程已创建。

构建基本提示流程 ​

基本提示流程完成后将如下所示：

要构建基础提示流程，请按照以下步骤操作：

  1. 点击输入，选择聊天输入组件，然后将其拖动到画布上。 聊天输入组件接受用户输入到聊天中。聊天输入

  2. 点击提示，选择提示组件，然后将其拖动到画布上。 提示组件将用户输入与用户定义的提示结合在一起。提示

  3. 点击输出，选择聊天输出组件，然后将其拖动到画布上。 聊天输出组件将流程的输出打印到聊天中。聊天输出

  4. 点击模型，选择OpenAI组件，然后将其拖动到画布上。 OpenAI模型组件将用户输入和提示发送到OpenAI API并接收响应。OpenAI

现在，你应该有一个看起来像这样的流程：

如果组件之间没有连接，它们将无法相互交互。您希望数据通过组件之间的连接从**聊天输入**传递到**聊天输出**。每个组件在左侧接受输入，并在右侧发送输出。将鼠标悬停在连接端口上，以查看组件接受的数据类型。有关组件输入和输出的更多信息，请参见[组件概述](/concepts-components)。

  1. 要将聊天输入组件连接到 OpenAI 模型组件，请点击并拖动一条线从蓝色的消息端口到 OpenAI 模型组件的输入端口。
  2. 要将提示组件连接到 OpenAI 模型组件，请点击并拖动一条线从蓝色的提示消息端口到 OpenAI 模型组件的系统消息端口。
  3. 要将OpenAI模型组件连接到聊天输出，请点击并拖动一条线从蓝色的文本端口到聊天输出组件的文本端口。

您完成的基本提示流应如下所示：

运行基本提示流 ​

将您的 OpenAI API 密钥添加到 OpenAI 模型组件中，并在提示组件中添加提示，指导模型如何响应。

  1. 将您的凭据添加到 OpenAI 组件中。 完成这些字段最快的方法是使用 Langflow 的全局变量。

    1. 在 OpenAI 组件的 OpenAI API 密钥字段中，点击 Globe 按钮，然后点击 Add New Variable。或者，点击右上角的用户名，然后点击 Settings、Global Variables，再点击 Add New。
    2. 为您的变量命名。在值字段中粘贴您的 OpenAI API 密钥（sk-…​）。
    3. 在 Apply To Fields 字段中，选择 OpenAI API 密钥字段，以将此变量应用于所有 OpenAI Embeddings 组件。

  2. 要向 Prompt 组件添加提示，点击 Template 字段，然后输入您的提示。 提示指导机器人的输入响应。如果您不确定提示内容，可以使用 Answer the user as if you were a GenAI expert, enthusiastic about helping them get started building something fresh.

  3. 点击 Playground 启动聊天会话。

  4. 输入查询，然后确保机器人根据您在 Prompt 组件中设置的提示进行响应。

您已成功使用 OpenAI 在 Langflow 工作区创建了一个聊天机器人应用程序。

添加向量RAG到您的应用程序 ​

您使用Langflow创建了一个聊天机器人应用程序，但让我们尝试做一个实验。

  1. 向机器人提问：2024年获得奥斯卡最佳影片奖的是谁？
  2. 机器人的回答类似于这样：
plaintext
I'm sorry, but I don't have information on events or awards that occurred after
October 2023, including the Oscars in 2024.
You may want to check the latest news or the official Oscars website
for the most current information.
1
2
3
4

嗯，这有点遗憾，但您可以通过检索增强生成（Retrieval Augmented Generation，简称RAG）加载更多最新的数据。

向量RAG允许您加载自己的数据并与之对话，为您的聊天机器人应用程序解锁更广泛的可能性。

添加向量 RAG 与 Astra DB 组件 ​

在基本的提示流基础上，通过 Astra DB 向量存储 组件将向量 RAG 添加到您的聊天机器人应用程序中。

用 Astra DB 组件作为向量存储，将文档摄取添加到您的基本提示流中。

TIP

如果您不想创建一个空白流，请点击 New Flow，然后选择 Vector RAG 来选择一个预构建的流。

添加向量 RAG 到基本提示流后，完成后看起来会是这样的：

要构建流程，请按照以下步骤操作：

  1. 通过双击连接线将 Chat Input 组件与 OpenAI 组件断开。

  2. 点击 Vector Stores，选择 Astra DB 组件，然后将其拖动到画布上。Astra DB vector store 组件连接到你的 Astra DB 数据库。

  3. 点击 Data，选择 File 组件，然后将其拖动到画布上。File 组件从你的本地计算机加载文件。

  4. 点击 Processing，选择 Split Text 组件，然后将其拖动到画布上。Split Text 组件将加载的文本拆分为更小的块。

  5. 点击 Processing，选择 Parse Data 组件，然后将其拖动到画布上。Data to Message 组件将 Astra DB 组件中的数据转换为纯文本。

  6. 点击 Embeddings，选择 OpenAI Embeddings 组件，然后将其拖动到画布上。OpenAI Embeddings 组件为用户输入生成嵌入，这些嵌入与数据库中的向量数据进行比较。

  7. 将新组件连接到现有流程，使你的流程看起来如下所示：

8. 配置 Astra DB 组件 ​

  1. 在 Astra DB Application Token 字段中，添加您的 Astra DB 应用程序令牌。该组件将连接到您的数据库，并使用现有数据库和集合填充菜单。
  2. 选择您的 Database。
  3. 选择您的 Collection。集合是在您的 Astra DB 部署 中创建的，用于存储向量数据。如果您没有集合，请参阅 DataStax Astra DB 无服务器文档。
  4. 选择 Embedding Model 来引入您自己的嵌入模型，这与连接的 OpenAI Embeddings 组件相关。Dimensions 值必须与您集合的维度匹配。此值可以在您的 Astra DB 部署 的 Collection 中找到。

如果您使用了 Langflow 的 Global Variables（全局变量）功能，RAG 应用程序流程组件已经配置了必要的凭证。

运行包含检索上下文的聊天机器人 ​

  1. 修改 Prompt 组件以包含用于 <code>{user_question}</code> 和 <code>{context}</code> 的变量。 <code>{context}</code> 变量为机器人提供了额外的上下文，用于回答 <code>{user_question}</code>，超出 LLM 已知的范围。
plaintext
Given the context
{context}
Answer the question
{user_question}
1
2
3
4
  1. 在 File 组件中，从本地机器上传一个文本文件，数据将被导入到 Astra DB 组件数据库中。此示例上传了一个关于奥斯卡获奖者的最新 CSV 文件。
  2. 点击 Playground 开始聊天会话。
  3. 向机器人提问：Who won the Oscar in 2024 for best movie?
  4. 机器人的回答应类似于以下内容：
plaintext
The Oscar for Best Picture in 2024 was awarded to "Oppenheimer,"
produced by Emma Thomas, Charles Roven, and Christopher Nolan.
1
2

通过添加 Astra DB 向量存储，您的聊天机器人已经进入了 2024 年。您已成功使用 Astra DB 组件将 RAG 添加到您的聊天机器人应用程序中。
