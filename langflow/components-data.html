Langflow 中的数据组件 ​

数据组件用于将数据从来源加载到您的流程中。

它们可能会执行一些处理或类型检查，例如将原始 HTML 数据转换为文本，或者确保您加载的文件类型是可接受的。

在流程中使用数据组件 ​

URL 数据组件从一组 URL 中加载内容。

在组件的 URLs 字段中，输入用逗号分隔的 URL 列表，你想加载的内容。或者，连接一个输出 Message 类型的组件，例如 Chat Input（聊天输入）组件，来通过组件提供你的 URL。

要输出 Data 类型，在 Output Format（输出格式）下拉菜单中，选择 Raw HTML（原始 HTML）。要输出 Message 类型，在 Output Format（输出格式）下拉菜单中，选择 Text（文本）。此选项会通过 data_to_text 辅助函数应用后处理。

在文档摄取管道的这个示例中，URL 组件将原始 HTML 输出到文本分割器，该分割器将原始内容分割成块，以供向量数据库摄取。

API 请求 ​

该组件使用 URL 或 cURL 命令发起 HTTP 请求。

Inputs ​

名称显示名称信息
urlsURLs输入一个或多个URL，用逗号分隔。
curlcURL粘贴curl命令以填充字典字段的headers和body。
methodMethod要使用的HTTP方法。
use_curlUse cURL启用cURL模式以从cURL命令填充字段。
query_paramsQuery Parameters要附加到URL的查询参数。
bodyBody随请求一起发送的主体，作为字典形式（用于 POST、PATCH、PUT）。
headersHeaders要随请求发送的头信息，作为字典形式。
timeoutTimeout要用于请求的超时时间。
follow_redirectsFollow Redirects是否跟随HTTP重定向。
save_to_fileSave to File将API响应保存到临时文件。
include_httpx_metadataInclude HTTPx Metadata在输出中包含诸如 headers、status_code、response_headers 以及 redirection_history 的属性。

输出 ​

名称显示名称信息
dataDataAPI 请求的结果。

目录 ​

该组件递归地从目录中加载文件，并可选择设置文件类型、深度和并发性。

Inputs ​

输入类型描述
pathMessageTextInput加载文件的目录路径
typesMessageTextInput要加载的文件类型（留空以加载所有类型）
depthIntInput搜索文件的深度
max_concurrencyIntInput加载文件的最大并发数
load_hiddenBoolInput如果为 true，加载隐藏文件
recursiveBoolInput如果为 true，则递归搜索
silent_errorsBoolInput如果为 true，错误不会触发异常
use_multithreadingBoolInput如果为 true，使用多线程

Outputs ​

OutputTypeDescription
dataList[Data]从目录加载的文件数据

File ​

FileComponent 是一个类，用于加载和解析多种支持格式的文本文件，将内容转换为一个Data对象。它支持多种文件类型，并提供静默错误处理选项。

支持的最大文件大小为100 MB。

输入 ​

名称显示名称信息
pathPath要加载的文件路径。
silent_errorsSilent Errors如果为 true，则错误不抛出异常。

输出 ​

名称显示名称信息
dataData作为Data对象解析的文件内容。

Webhook ​

该组件定义了一个 webhook 触发器，当接收到 HTTP POST 请求时，会运行一个流程。

如果输入不是有效的 JSON，对象就会被包裹在一个 payload 对象中，便于处理并仍然触发流程。该组件不需要 API 密钥。

当在工作区添加一个 Webhook 组件时，API 面板中会出现一个新的 Webhook cURL 选项卡，其中包含用于触发 webhook 组件的 HTTP POST 请求。例如：

bash
curl -X POST \
  "http://127.0.0.1:7860/api/v1/webhook/**YOUR_FLOW_ID**" \
  -H 'Content-Type: application/json'\
  -d '{"any": "data"}'

测试 webhook 组件的方法：

  1. 添加一个 Webhook 组件到流程中。
  2. 将 Webhook 组件的 Data 输出连接到 Data to Message 组件的 Data 输入。
  3. 将 Data to Message 组件的 Message 输出连接到 Chat Output 组件的 Text 输入。
  4. 在 API 面板中的 Webhook cURL 选项卡中复制代码，然后粘贴到终端。
  5. 发送 POST 请求。
  6. 打开 Playground。 你的 JSON 数据将被发送到 Chat Output 组件，这表明 webhook 组件已正确触发流程。

Inputs ​

NameTypeDescription
dataString用于测试 webhook 组件的 JSON 负载

Outputs ​

名称类型描述
output_dataData 数据从 webhook 输入中处理的数据信息
