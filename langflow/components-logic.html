Langflow中的逻辑组件 ​

逻辑组件为路由、条件处理和流管理提供功能。

在流程中使用逻辑组件 ​

此流程使用 循环 (Loop) 组件创建一个汇总的 "for each" 循环。

该组件遍历 数据 (Data) 对象的列表，直到完成，然后 完成 (Done) 循环汇总结果。

文件 (File) 组件从本地计算机加载文本文件，然后 解析数据 (Parse Data) 组件将其解析为结构化的 数据 (Data) 对象列表。 循环 (Loop) 组件将每个 数据 (Data) 对象传递给一个 提示 (Prompt) 进行汇总。

当 循环 (Loop) 组件没有 数据 (Data) 时，完成 (Done) 循环激活，它通过另一个 提示 (Prompt) 计算页数并汇总其语气。 在 Langflow 中，这通过将解析数据组件的 数据列表 (Data List) 输出连接到循环组件的 数据 (Data) 循环输入来表示。

条件路由器（If-Else 组件） ​

​

该组件根据文本比较将输入消息路由到相应的输出。

ConditionalRouterComponent（条件路由器组件）基于文本比较路由消息。它通过使用指定的运算符比较两个文本输入来评估条件，并相应地路由消息。

Inputs ​

NameTypeDescription
input_textString操作的主要文本输入。
match_textString需要进行比较的文本输入。
operatorDropdown用于比较文本的运算符。
case_sensitiveBoolean如果为真，则比较时区分大小写。
messageMessage要通过任一路径传递的消息。
max_iterationsInteger条件路由器的最大迭代次数。
default_routeDropdown达到最大迭代次数时采用的默认路径。

输出 ​

名称类型描述
true_resultMessage条件为真时的输出。
false_resultMessage条件为假时的输出。

Data条件路由器 ​

该组件基于指定键的条件（包括布尔验证）路由Data对象。

此组件在需要对复杂数据结构进行条件路由的工作流中特别有用，使得能够基于数据内容进行动态决策。

输入 ​

名称类型描述
data_inputData要处理的数据对象或数据对象列表。
key_nameString要检查的数据对象中键的名称。
operatorDropdown用于比较值的运算符。
compare_valueString要比较的值（不用于布尔验证器）。

Outputs ​

名称类型描述
true_output数据/列表条件满足时的输出。
false_output数据/列表条件不满足时的输出。

Flow 作为工具 ​

INFO

此组件自 Langflow 版本 1.1.2 起不推荐使用。 请使用 运行 Flow 组件。

该组件从一个运行已加载 Flow 的函数构建一个工具。

Inputs ​

NameTypeDescription
flow_nameDropdown要运行的流程名称。
tool_nameString工具的名称。
tool_descriptionString工具的描述。
return_directBoolean如果为 true，直接从工具返回结果。

输出 ​

名称类型描述
api_build_toolTool从流程构建而成的工具。

Listen ​

此组件监听通知并检索其相关状态。

Inputs ​

名称类型描述
nameString要监听的通知的名称。

输出 ​

名称类型描述
outputData与通知关联的状态。

Loop ​

该组件遍历一个 数据 对象列表，每次输出一个项目，并从循环输入中汇总结果。

Inputs ​

NameTypeDescription
data数据/列表要迭代的初始数据对象列表。

Outputs ​

名称类型描述
item数据一次从数据列表中输出一项。
done数据迭代完成时触发，返回聚合结果。

Notify ​

此组件生成一个通知供 Listen 组件使用。

Inputs ​

名称类型描述
nameString通知的名称。
dataData要存储在通知中的数据。
appendBoolean如果为 true，记录将附加到已有的通知。

Outputs ​

NameTypeDescription
outputData存储在通知中的数据。

传递消息 ​

该组件会不改变地转发输入消息。

Inputs ​

NameDisplay NameInfo
input_messageInput Message将要传递的信息。
ignored_messageIgnored Message第二条将被忽略的信息。用于连续性的权宜之计。

Outputs ​

名称显示名称信息
output_messageOutput Message转发的输入信息。

运行流程 ​

该组件允许您在不打开流程编辑器的情况下运行存储在您Langflow数据库中的任何流程。

当连接到一个Agent时，运行流程组件也可以作为一个工具使用。Agent用来注册工具的name和description元数据会被自动创建。

当您选择一个流程时，组件会获取该流程的图结构，并使用它来生成运行流程组件的输入和输出。

要将运行流程组件用作工具，请执行以下操作：

Inputs ​

名称类型描述
flow_name_selectedDropdown要运行的流程名称。
flow_tweak_dataDict自定义流程行为的调整字典。
dynamic inputsVarious根据选定的流程生成的附加输入。

Outputs ​

名称类型描述
run_outputs类型为 Data、Message 或 DataFrame 的 List（列表）所有输出均由执行流程生成。

Sub flow ​

INFO

important 本组件自 Langflow 版本 1.1.2 起已被弃用。建议使用运行流程组件。

SubFlowComponent 组件生成一个包含流程所有输入输出的组件。

这个组件可以将整个流程集成为更大工作流中的一个组件。它会根据所选的流程动态生成输入，并使用提供的参数执行流程。

输入 ​

名称类型描述
flow_nameDropdown要运行的流程名称。

输出 ​

名称类型描述
flow_outputsList[Data]从流中生成的输出。
