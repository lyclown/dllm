Langflow 组件概览 ​

组件是流程中的单个构建块，具有输入、输出、功能和参数来定义其功能。单个组件就像是一个更大应用程序中的一个类。

要向流程中添加组件，请从组件菜单中将其拖动到工作区。

在本页了解更多关于组件及其工作方式的信息。

组件菜单 ​

每个组件都是独特的，但所有组件的顶部都有一个类似如下的菜单栏：

使用组件控件以执行以下操作：

  • 代码 — 修改该组件的 Python 代码并保存您的更改。
  • 控件 — 调整所有组件参数。
  • 冻结路径 — 组件运行后，锁定其之前的输出状态以防止再次运行。

点击 全部 查看组件的其他选项。

要查看组件的输出和日志，请点击 图标。

要运行一个单独的组件，请点击 播放。

一个 勾选标记 表示组件运行成功。

通过 播放 按钮运行单个组件与运行整个流程是不同的。在单个组件运行中，调用 build_vertex 函数，它仅构建并运行提供通过 UI 提供直接输入的单个组件（即 inputs_dict 参数）。VertexBuildResult 数据传递到 build_and_run 方法，该方法调用组件的 build 方法并运行它。与运行完整流程不同，运行单个组件不会自动执行其上游依赖。

组件端口 ​

组件侧面的连接点（）指示可以在该端口连接的输入和输出类型。将鼠标悬停在连接点上以查看连接详情。

组件代码 ​

组件继承自一个基础的 Component 类，该类定义了组件的接口和行为。

例如， 递归字符文本拆分器 是 LCTextSplitterComponent 类的子类。

python
from typing import Any
from langchain_text_splitters import RecursiveCharacterTextSplitter, TextSplitter
from langflow.base.textsplitters.model import LCTextSplitterComponent
from langflow.inputs.inputs import DataInput, IntInput, MessageTextInput
from langflow.utils.util import unescape_string

class RecursiveCharacterTextSplitterComponent(LCTextSplitterComponent):
    display_name: str = "递归字符文本分割器"
    description: str = "尝试保持所有相关文本在一起的文本分割工具。"
    documentation: str = "https://docs.langflow.org/components-processing"
    name = "RecursiveCharacterTextSplitter"
    icon = "LangChain"

    inputs = [
        IntInput(
            name="chunk_size",
            display_name="块大小",
            info="每个块的最大长度。",
            value=1000,
        ),
        IntInput(
            name="chunk_overlap",
            display_name="块重叠",
            info="块之间的重叠量。",
            value=200,
        ),
        DataInput(
            name="data_input",
            display_name="输入",
            info="要分割的文本。",
            input_types=["Document", "Data"],
        ),
        MessageTextInput(
            name="separators",
            display_name="分隔符",
            info='用于分割的字符。\n如果留空，默认为 ["\\n\\n", "\\n", " ", ""].',
            is_list=True,
        ),
    ]

    def get_data_input(self) -> Any:
        return self.data_input

    def build_text_splitter(self) -> TextSplitter:
        if not self.separators:
            separators: list[str] | None = None
        else:
            # 检查分隔符列表中是否有转义字符
            # 如果有转义字符，则取消转义
            separators = [unescape_string(x) for x in self.separators]

        return RecursiveCharacterTextSplitter(
            separators=separators,
            chunk_size=self.chunk_size,
            chunk_overlap=self.chunk_overlap,
        )

组件包括对输入和输出的定义，这些定义在UI（用户界面）中通过颜色编码的端口表示。

输入定义： 每个输入（如 IntInput 或 DataInput）会指定输入的类型、名称和显示属性，这些属性在组件的UI面板中作为可配置字段显示。

方法： 组件拥有处理其功能的方法或函数。这个组件包含两个方法。 get_data_input 从组件的输入中检索要拆分的文本数据。这使得数据可以被类所使用。 build_text_splitter 通过调用其父类的 build 方法创建一个 RecursiveCharacterTextSplitter（递归字符文本拆分器）对象。文本通过创建的拆分器进行拆分，并传递到下一个组件。 在流程中使用时，这个组件：

  1. 在UI中显示其配置选项。
  2. 根据输入类型验证用户输入。
  3. 使用配置的参数处理数据。
  4. 将结果传递给下一个组件。

Freeze Path ​

在组件运行后，Freeze Path 将锁定组件之前的输出状态，以防止其重新运行。

如果您期待组件具有一致的输出，并且不需要重新运行，请点击 Freeze Path。

启用 Freeze Path 将冻结选定组件上游的所有组件。

如果您只希望冻结单独的组件，请选择 Freeze。

一个 会显示在所有冻结的组件上。

要修改组件的名称或描述，请双击 名称 或 描述 字段。组件描述支持 Markdown 语法。

组合工作区中的组件 ​

多个组件可以组合成一个单独的组件以便重复使用。这在例如将大型流程（如 RAG 与向量数据库结合）组合成单个组件时特别有用，同时也节省了空间。

  1. 按住 Shift 并拖动以选择组件。
  2. 选择 Group（组合）。这些组件会合并为一个单独的组件。
  3. 双击名称和描述以更改它们。
  4. 将您的组合组件保存到侧边栏中以便日后使用。

组件版本 ​

组件的初始状态存储在数据库中。一旦你将组件从侧边栏拖动到工作区，这两个组件就不再同步。

组件保持其在工作区初始化时的版本号。如果一个组件在被拖入工作区时的版本是 1.0，那么它将保持在 1.0 版本，直到你更新它为止。

当组件的工作区版本落后于数据库版本并且可以更新时，Langflow 会通知你。点击 更新组件 图标以将组件更新到 最新 版本。这会在原地更改组件的代码，以便你可以通过检查其更新前后的 Python 代码来验证组件已更新。

组件侧边栏 ​

组件按照组件类型列在侧边栏中。

组件捆绑包是按照提供者分组的组件。例如，Langchain 模块中的 RunnableExecutor 和 CharacterTextSplitter 被分组在 Langchain 捆绑包下。

侧边栏包括一个组件搜索栏，并包含用于显示或隐藏测试版和旧版组件的标志。

测试版组件仍在测试中，不适合用于生产工作负载。

旧版组件仍可使用，但不再支持。
