AssemblyAI ​

AssemblyAI 组件允许您为您的应用应用强大的语音 AI 模型，以完成以下任务：

  • 转录音频和视频文件
  • 格式化转录内容
  • 生成字幕
  • 将大型语言模型（LLMs）应用于音频文件

关于 AssemblyAI 的更多信息：

  • 官方网站
  • AssemblyAI API 文档
  • 获取免费 API 密钥

先决条件 ​

您需要一个 AssemblyAI API 密钥。创建一个免费账户后，您将在您的控制面板中找到该 API 密钥。在此获取免费 API 密钥。

在所有需要 API 密钥的组件中，输入 AssemblyAI API 密钥。

（可选）：要使用 LeMUR 功能，您需要升级您的 AssemblyAI 账户，因为这不包含在免费账户中。

组件 ​

AssemblyAI 开始转录 ​

该组件允许您提交一个音频或视频文件进行转录。

提示：您可以冻结该组件的路径，只提交一次文件。

  • 输入：

    • AssemblyAI API 密钥：您的 API 密钥。
    • 音频文件：要转录的音频或视频文件。
    • 语音模型（可选）：选择模型的类别。默认是 最佳。详情请参见语音模型。
    • 自动语言检测（可选）：启用自动语言检测。
    • 语言（可选）：音频文件的语言。如果禁用了自动语言检测，可以手动设置。查看支持的语言获取支持的语言代码列表。
    • 开启说话人标签（可选）：检测音频中的讲话者，并识别每个讲话者所说的内容。
    • 预期说话人数（可选）：如果开启了说话人标签，则设置预期的说话人数。
    • 音频文件 URL（可选）：待转录的音频或视频文件的 URL。可替代 音频文件 使用。
    • 加标点（可选）：应用标点符号。默认值为 true。
    • 格式化文本（可选）：应用大小写和文本格式化。默认值为 true。

  • 输出：

    • 转录 ID：转录的 ID。

AssemblyAI Poll Transcript ​

该组件允许您轮询转录结果。它每隔几秒钟检查一次转录的状态，直到转录完成。

  • 输入：

    • AssemblyAI API 密钥：您的 API 密钥。
    • 轮询间隔（可选）：轮询的时间间隔，以秒为单位。默认值为 3 秒。

  • 输出：

    • 转录结果：包含已完成转录的 AssemblyAI JSON 响应，包含文本和其他信息。

AssemblyAI 获取字幕 ​

该组件允许您生成 SRT 或 VTT 格式的字幕。

  • 输入：

    • AssemblyAI API Key: 您的 API 密钥。
    • Transcription Result: Poll Transcript（轮询转录）组件的输出。
    • Subtitle Format: 字幕的格式（SRT 或 VTT）。
    • Character per Caption (Optional): 每个字幕的最大字符数（0 表示无限制）。

  • 输出：

    • Subtitles: 一个包含 subtitles 字段的 JSON 响应，其中包含 SRT 或 VTT 格式的字幕。

AssemblyAI LeMUR ​

该组件允许你使用 AssemblyAI LeMUR 框架 将大语言模型（Large Language Models，LLMs）应用于语音数据。

LeMUR 会自动将转录结果作为附加上下文进行导入，使得将 LLM 应用于音频数据变得简便。你可以将其用于总结音频、提取见解或提问等任务。

  • 输入：

    • AssemblyAI API 密钥：你的 API 密钥。
    • 转录结果：Poll Transcript 组件的输出。
    • 输入提示：用于提示模型的文本。你可以在该字段中输入提示文本，或将其连接到 Prompt 组件。
    • 最终模型：进行压缩后的最终提示所使用的模型。默认是 Claude 3.5 Sonnet。
    • 温度（可选）：用于模型的温度。默认是 0.0。
    • 最大输出大小（可选）：以 token 为单位的最大输出大小，最多 4000。默认是 2000。
    • 端点（可选）：使用的 LeMUR 端点。默认是 "task"。对于 "summary" 和 "question-answer"，不需要提示输入。更多信息请参见 LeMUR API 文档。
    • 问题（可选）：用逗号分隔的问题列表。仅在 Endpoint 为 "question-answer" 时使用。
    • 转录 ID（可选）：用逗号分隔的转录 ID 列表。LeMUR 可以在多个转录上执行操作。如果提供了该项，则忽略 Transcription Result。

  • 输出：

    • LeMUR 响应：生成的 LLM 响应。

AssemblyAI 列出抄本(transcripts) ​

该组件可以作为一个独立组件，用于列出所有先前生成的抄本。

  • 输入：

    • AssemblyAI API Key: 你的 API 密钥。
    • Limit (可选): 要检索的抄本的最大数量。默认值为 20，使用 0 代表获取全部。
    • Filter (可选): 按照抄本状态进行筛选。
    • Created On (可选): 仅获取在此日期创建的抄本（YYYY-MM-DD）。
    • Throttled Only (可选): 仅获取受限制的抄本，该选项会覆盖状态筛选。

  • 输出：

    • Transcript List: 包含所有抄本的信息列表，如抄本 ID、状态和数据等。

流程 ​

  1. 用户输入一个音频或视频文件。
  2. 用户还可以输入一个 LLM 提示。在这个例子中，我们希望生成转录的摘要。
  3. 流程将音频文件提交进行转录处理。
  4. 流程每隔几秒检查一次转录状态，直至转录完成。
  5. 流程解析转录结果并输出转录文本。
  6. 流程同时生成字幕。
  7. 流程应用 LLM 提示生成摘要。
  8. 作为一个独立的组件，可以列出所有转录内容。

运行转录和语音 AI 流程 ​

要运行转录和语音 AI 流程：

  1. 打开 Langflow 并创建一个新项目。
  2. 将上述组件添加到您的流程画布，或者下载 AssemblyAI 转录和语音 AI 流程(下载链接)并导入该 JSON 文件到 Langflow。
  3. 按照流程图所示连接组件。提示：冻结 Start Transcript（开始转录）组件的路径，以便仅提交一次文件。
  4. 在所有需要 AssemblyAI API 密钥的组件中输入密钥（Start Transcript、Poll Transcript、Get Subtitles、LeMUR、List Transcripts）。
  5. 在 Start Transcript 组件中选择一个音频或视频文件。
  6. 通过点击 Parse Data（解析数据）组件上的播放按钮运行流程。请确保指定的模板为 {text}。
  7. 要生成字幕，点击 Get Subtitles（获取字幕）组件上的播放按钮。
  8. 要将 LLM 应用到您的音频文件，点击 LeMUR 组件上的播放按钮。注意，使用 LeMUR 需要升级的 AssemblyAI 账户。
  9. 要列出所有转录，点击 List Transcript（列出转录）组件上的播放按钮。

自定义​ ​

流程可以通过以下方式进行自定义：

  1. 修改 Start Transcript 组件中的参数。
  2. 修改 Get Subtitles 组件中的字幕格式。
  3. 修改 LeMUR 组件输入的 LLM（大模型，Large Language Model）提示。
  4. 修改 LeMUR 组件中的 LLM 参数（例如：温度）。

故障排除 ​

如果您遇到问题：

  1. 确保在所有需要使用 API 密钥的组件中正确设置了 API 密钥。
  2. 要使用 LeMUR，您需要升级您的 AssemblyAI 账户，因为这不包含在免费账户中。
  3. 验证所有组件是否在流程中正确连接。
  4. 查看 Langflow 日志以获取任何错误信息。

有关更高级的用法，请参阅 AssemblyAI API 文档。如果您需要更多帮助，可以联系 AssemblyAI 支持。
