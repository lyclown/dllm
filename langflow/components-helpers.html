Langflow 中的辅助组件 ​

辅助组件提供实用功能，帮助管理数据、任务以及流中的其他组件。

在流程中使用辅助组件 ​

在 Langflow 中，聊天记录存储在本地 Langflow 表中使用 LCBufferMemory，或者连接到外部数据库中。

**Store Message（存储消息）辅助组件将聊天记录存储为数据对象，而Message History（消息历史）**辅助组件则将聊天消息作为数据对象或字符串检索。

这个示例流程使用**Store Message（存储消息）和Chat Memory（聊天内存）**组件，从AstraDBChatMemory组件中存储和检索聊天历史记录。

Batch Run Component ​

Batch Run 组件在一个 DataFrame 的文本列的每一行上运行一个语言模型，并返回一个新的 DataFrame，其中包含原始文本和模型的响应。

Inputs ​

名称显示名称类型信息必需
modelLanguage ModelHandleInput在此连接您的 LLM 组件的 'Language Model' 输出。是
system_messageSystem MessageMultilineInput针对 DataFrame 中所有行的多行系统指令。否
dfDataFrameDataFrameInput要将其列（由 'column_name' 指定）视为文本消息的 DataFrame。是
column_nameColumn NameStrInput要视为文本消息的 DataFrame 列的名称。默认值='text'。是

Outputs ​

NameDisplay NameMethodInfo
batch_resultsBatch Resultsrun_batch一个包含两列的数据框：'text_input' 和 'model_response'。

创建列表 ​

该组件动态生成一个具有指定字段数量的记录。

输入 ​

NameDisplay NameInfo
n_fields字段数量要添加到记录中的字段数量。
text_key文本键用作文本的键。

Outputs ​

名称显示名称信息
listList动态创建的包含指定字段数量的列表。

当前日期 ​

当前日期组件返回所选时区的当前日期和时间。此组件提供了一种灵活的方法，可以在 Langflow 数据管道中获取特定时区的日期和时间信息。

Inputs ​

NameDisplay NameInfo
timezoneTimezone选择当前日期和时间的时区。

输出 ​

名称显示名称信息
current_dateCurrent Date结果中的当前日期和时间，按照所选时区显示。

ID 生成器 ​

该组件用于生成唯一的 ID。

Inputs ​

NameDisplay NameInfo
unique_idValue生成的唯一ID。

Outputs ​

NameDisplay NameInfo
idID生成的唯一 ID。

Message history ​

INFO

在 Langflow 1.1 版本之前，该组件被称为 Chat Memory 组件。

该组件从 Langflow 表或外部内存中检索和管理聊天消息。

Inputs ​

名称显示名称信息
memory外部内存从外部内存中检索消息。如果为空，将使用 Langflow 表。
sender发送者类型按发送者类型进行过滤。
sender_name发送者名称按发送者名称进行过滤。
n_messages消息数量要检索的消息数量。
session_id会话 ID聊天的会话 ID。如果为空，将使用当前会话 ID 参数。
order顺序消息的排序顺序。
template模板用于格式化数据的模板。可以包含键 {text}、{sender} 或消息数据中的任何其他键。

输出 ​

NameDisplay NameInfo
messagesMessages (Data)检索到的消息作为数据对象。
messages_textMessages (Text)检索到的消息格式化为文本。
lc_memoryMemory一个构造的 Langchain ConversationBufferMemory 对象。

消息存储 ​

该组件将聊天消息或文本存储到 Langflow 表或外部存储中。

它在聊天系统中提供了管理消息存储和检索的灵活性。

Inputs ​

名称显示名称信息
messageMessage要存储的聊天消息。（必需项）
memoryExternal Memory用于存储消息的外部内存。如果为空，将使用 Langflow 表。
senderSender消息的发送者。可以是 Machine 或 User。如果为空，将使用当前发送者参数。
sender_nameSender Name发送者的名称。可以是 AI 或 User。如果为空，将使用当前发送者参数。
session_idSession ID聊天的会话 ID。如果为空，将使用当前会话 ID 参数。

输出 ​

名称显示名称信息
stored_messagesStored Messages当前消息添加后的存储消息列表。

结构化输出 ​

此组件将 LLM（大语言模型）的响应转换为结构化数据格式。

输入 ​

名称显示名称信息
llm语言模型用于生成结构化输出的语言模型。
input_value输入消息供语言模型处理的输入消息。
schema_name模式名称为输出数据模式提供一个名称。
output_schema输出模式定义模型输出的结构和数据类型。
multiple生成多个如果模型需要生成一个输出列表而非单个输出，请设置为 True。

输出 ​

名称显示名称信息
stored_messagesStored Messages基于定义的架构的结构化输出。
